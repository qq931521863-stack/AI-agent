03增益曲线：你真正只需要理解这一张图

LLC 所有的"玄学"都收敛到一条曲线。看懂它，剩下的都是查表和算术；看不懂它，背一百个公式也没用。

3.1　一个式子

用基波近似（FHA），把方波输入只取基波、把整流桥和负载等效成一个电阻，整个谐振腔就是一个分压网络：

M(fn) = 1 / | 1 + (1/k)(1 − 1/fn²) + j·Q·(fn − 1/fn) |
fn = fsw / fr　归一化频率　　k = Lm/Lr　　Q = Z0/Rac　　Rac = 8n²Vo²/(π²Po)

三个量，各管一件事，记住这个对应关系就不会乱：

  • fn 管"现在在哪"——低于 1 是升压区（增益 >1），高于 1 是降压区（增益 <1），等于 1 时增益恰好 = 1，与负载无关。
  • k 管"能升多高、能降多低"——k 小则峰值高、地板低；k 大则相反。
  • Q 管"负载轻重"——Q 大是重载（曲线矮而宽），Q 小是轻载（曲线高而尖）。
图 3-1　本机增益曲线（k = 6.67）。横轴归一化频率 fn，纵轴增益 M。四条曲线对应四个负载：Q = 0.05（极轻载参考）、0.322（60V/1600W）、0.475（45.7V/30A）、1.0（重载参考）。虚线是 增益地板 k/(k+1) = 0.870，它下面是一片"任何频率都到不了"的死区。

3.2　地板：一条曲线里最容易被忽略、又最致命的东西

把 M(fn) 里的 Q 取 0（空载），式子塌缩成一个极简形式：

M(fn) |Q→0 = k / ( k + 1 − 1/fn² )　　→　　fn → ∞ 时　M → k / (k+1)
代入 k = 6.67：　M_min = 6.67 / 7.67 = 0.870
为什么会有地板

物理上：频率越高，Lr 的阻抗越大，它把电流"掐"得越小。但 Lm 是和负载并联的——负载再轻，Lm 始终在分流。当频率无穷高时，Lr 把电流掐到几乎为零，而这点残余电流全部流过 Lm，不流向负载。此时的分压比就是 Lm 与 (Lr+Lm) 的分压：Lm/(Lr+Lm) = k/(k+1)。

换句话说，空载时 LLC 的最低输出电压，被 k 锁死了。频率再高也没用，因为能量根本过不去。

这条地板线的后果非常具体：你这台机器的 k = 6.67，地板 0.870，而 M = 2n·Vo/Vin = 8Vo/Vin。所以

Vo_floor = 0.870 × Vin / 8 = 0.1087 × Vin
Vin = 360 V → 39.1 V　　Vin = 380 V → 41.3 V　　Vin = 400 V → 43.5 V

记住 39.1 这个数。下一章你会发现它就在你的固件里，一个字节都没差。

0439V 不是拍脑袋：固件里的数字从哪来

mathR02.c 的 OvLoadPFM 分支里有这么一段：

if (ADSample_Info.vOut_Bat_adc < 39.0f) {
  time++;
  if (time > 400) { DrvH = 0; DrvL = 0; SynDrv = 0; ... 回到 Charging 状态 }
} else time = 0;

写这段代码的人没有随便挑 39。它正好是第 3 章算出来的地板电压：0.870 × 360 / 8 = 39.1 V。

含义是：母线最低 360V 时，空载能把输出压到的最低值就是 39.1V。再往下，PFM 无论怎么提高频率都压不住，输出会被"顶"在 39V 以上。所以代码只能这样处理——掉到 39V 以下就说明已经失控了，关机重来。

这条证据链的价值

它同时证明了三件事：① 我对 k = 6.67 的反推是对的；② 母线地板确实是 360V；③ 这台机器的软件是在"物理边界"上做保护的，不是拍的余量。

更重要的是，它给了你一个可迁移的判据：以后看到任何 LLC 固件里的低压门限，先算 k/(k+1)×Vin_min/(2n)，对得上就说明设计者懂；对不上就说明那个门限是别的原因（比如电池欠压保护），别混为一谈。

两个门限，分工不同

固件里其实有两个和地板有关的数字，很容易混成一个：

39.0V —— PFM 区里的失控保护。OvLoadPFM 状态下，Vo 掉到 39V 以下持续 400 周期，关驱动、回 Charging 重启。它防的是"频率已经拉到上限、输出还是压不住"。

40.2V —— 硬开关区到谐振区的交接门限。Vo 涨到 40.2V 持续 400 周期，收窄 Duty、等电流降到 1A、再切 PFM。它防的是"还没到地板就把控制权交出去"。

两者差 1.2V，正好是一个滞环。这个设计是对的——但 40.2V 这个值只在母线 370V 附近才落在真正的边界上，第 5.6 节会展开。

0530–40V 段根本不在 LLC 谐振区

这一章是上一版的修正。上一版我把 30–40V 当成 LLC 的稳态工作点，套 FHA 增益曲线，算出"40V/3A 需要 990kHz，物理不可行"。你指出这段是对称发波、全程硬开——这个纠正把整章的前提推翻了。回去读代码，确实如此，而且证据很硬。

一句话结论

30–40V 段走的是 80kHz 定频 + 对称占空比调制 + 容性区硬开关，它的增益由 D 决定，不由 fn 决定。FHA 增益曲线在这段不适用，所以"990kHz 不可行"这个结论本身就问错了问题。

这一段不是缺口，是架构分工：PFM 管 42–60V，硬开关 PWM 管 30–42V，两者在 40.2V 交接。

5.1　发波机制：两组 CMP 公式，两种拓扑

全部答案在 ConsoleFast.c:163–204 的 SHRTIMERdrive() 里。它只有两条分支，差别不在频率，而在CMP1–CMP4 怎么写：

// PFM 分支：CtrMode == OvLoadPFM
CMP1 = LLC_DEADTIME　　　　CMP2 = half − LLC_DEADTIME
CMP3 = half + LLC_DEADTIME　CMP4 = pre − LLC_DEADTIME
→ 上下管各占 50%，相位严格互补，只改 PER 变频

// PWM 分支：其余所有状态
temp = pre / 4　　bemp = pre − temp　　duty = half × Duty
CMP1 = temp − duty　　CMP2 = temp + duty
CMP3 = bemp − duty　　CMP4 = bemp + duty
→ 两路脉冲等宽（宽度 = pre × Duty），分别居中于周期的 25% 与 75%，相位差 180°

这就是你说的"对称发波"：两路占空比相等、对称分布在半周期两侧，中间留出 50%−D 的间隔。它不是 LLC 的变频控制，而是一个定频的、占空比控制的半桥，只是恰好接着 LLC 的谐振腔在用。

5.3　为什么 80kHz 一定是硬开关

不是"代码没做 ZVS"，是物理上做不到。判据是谐振腔在开关频率下的等效阻抗性质——容性则硬开关，感性才可能 ZVS：

注意 40kHz 那一行：预充段反而是感性的（+86Ω）。因为频率够低，Lm 的电抗小于 Cr 的容抗，整体被 Lm 拉回感性。而 80kHz 正好落在两者交叉的容性区里——这就是为什么 30–40V 恒流段必须硬开，不是选择，是位置决定的。

5.4　这段的增益由 Duty 决定，不由 fn 决定

对称 PWM 下，桥臂输出的基波幅值被 sin(πD) 削掉，所以总增益近似为：

M_total ≈ M_FHA(fn) × sin(πD)
M_FHA 是谐振腔在 80kHz（fn=0.642）的固有增益，轻载约 1.27、满载约 1.08；sin(πD) 是占空比对基波的削减
Vo = M_total × Vin / (2n) = M_total × Vin / 8

这个模型的边界

sin(πD) 是基波近似，忽略了谐波、死区、以及容性区的电流畸变，所以表 5-4 只能看趋势和量级，不能当设计公式用。真实对应关系必须在样机上扫 Duty–Vo 曲线标定。但它足以回答"30–40V 做不做得到"——做得到，Duty 在 0.2 附近。

标定用的工具已经做好了：duty-vo-calibration.html。填入实测点，它会自动算每点偏差、反推 M_FHA 有效值，并判断模型是"结构对系数偏"还是"近似已失效"。第 4 节还能直接算交接点该不该改。

5.5　这段真正的约束（不是增益曲线，是这四条）

约束 1死区吃掉脉宽
Duty=0.02 时脉宽 250ns，死区 176ns，有效导通只剩 74ns。这就是 0.02 成为硬下限的原因：再往下就没有脉冲了。
约束 2Coss 全部耗散
容性区开通，Coss 储能全在 MOS 内部烧掉。按 Coss≈0.5–1nF、400V、80kHz 估算，这部分损耗约 3–13W，与输出功率无关，是纯固定损耗。
约束 3同步整流关闭
ConCurrHandle 里 SynDrv = 0，副边走体二极管。几 A 时压降损耗尚可（2×0.7V×3A≈4W），但这段不能带大电流，30A 会烧。
约束 4偏磁风险
对称发波理论上伏秒平衡，但死区、驱动延时不对称会累积直流偏磁。硬开关段电流小、励磁弱，抗偏磁能力比 PFM 段差，这是长时工作的隐性风险。

5.6　一个需要你实测确认的疑点

把 40.2V 这个交接点代回增益地板，会发现它只在特定母线电压下成立：

PFM 最低可调电压 = (k/(k+1)) × Vin / (2n) = 0.8696 × Vin / 8
Vin=360V → 39.1V　　Vin=370V → 40.2V　　Vin=380V → 41.3V
Vin=400V → 43.5V　　Vin=410V → 44.6V

40.2V 正好对应 Vin=370V。也就是说：

  • 如果 PFC 母线在低压输入时确实掉到 370V 附近，这个门限是对的；
  • 如果母线稳在 400V，那么切进 PFM 的瞬间，PFM 的最低可调电压是 43.5V，高于 40.2V，输出会往上跳 3V 左右，电流环再把它拉回来——表现为交接点的一次电压台阶。

这是推断，不是结论。验证方法很简单：在交接瞬间抓 vOut_Bat_adc 和 Chrgr_LlcFreq 的 CAN 波形，看电压有没有台阶、频率是不是一步跳到低频端。如果有台阶，说明门限该按实际母线重算（Vo_th ≈ 0.87 × Vin / 8），这属于一个可以靠改一个常量解决的调参问题，不是设计缺陷。

所以，30–40V 到底要不要做 burst？

不需要。上一版说"burst 是唯一出路"是错的，因为当时没看到这条 80kHz 硬开关通路。现在的事实是：这条路已经能覆盖 30–42V 恒流，代价是效率低、SR 关闭、不能带大电流——而这三点恰好与"只要几 A"的工况匹配。

真正该做的不是补 burst，而是三件小事：① 实测 Duty–Vo 曲线，把 0.02–0.4 的限幅标定准；② 确认交接点不跳变（5.6）；③ 如果这段要长时间工作，量一下 MOS 壳温，确认那 3–13W 硬开关损耗撑得住。

06正向设计（一）：匝比 n 怎么定

从这里开始是"如果让你从零设计，该怎么走"。三个自由度：n、k、fr（或 Z0）。顺序不能反，因为后一个依赖前一个。

6.1　判据：让 M = 1 落在工作区的中点

M = 1 对应 fn = 1，也就是"刚好在谐振点"。这是 LLC 效率最高、波形最干净的点，应该让它落在最常工作、功率最大的电压上。

n = Vin_nom / (2 × Vo_center)
本机：Vin_nom = 400V，Vo_center = 50V（30–60V 的中点，也是额定功率点附近）
n = 400 / (2 × 50) = 4.0　→　取 16T : 4T+4T

为什么中心取 50V 而不是 45V 或 55V？因为 50V 时 M=1，效率最高；而 45.7V 是 1600W 恒功率的起点，正好在 M=1 附近偏一点（M=1.000 @50V，0.914 @45.7V）。如果取 45V 为中心，50–60V 段就要长期工作在 M>1 的升压区，环流大、效率低。

一个容易踩的坑

很多人按 Vo_max 定 n，理由是"最高电压要能做到"。这是反的。按 Vo_max 定 n 会让整个工作区偏向升压侧，长期在低 fn 运行，励磁环流大、效率低，而且峰值增益余量被吃掉。

正确做法：按中心电压定 n，用 k 去保证 Vo_max 够得着。n 管"工作在哪"，k 管"能到多高"。

08正向设计（三）：fr、Z0 与 Q

8.1　Q 选在哪个区间

Q = Z0/Rac 是"谐振腔阻抗"和"负载折算阻抗"的比值。它决定了曲线是尖还是平：

表 8-1　Q 的取舍
Q 范围曲线形态后果
0.1 – 0.25很尖，峰值高峰值余量足，但轻载时频率范围极宽，环路难调
0.3 – 0.5适中主流取值。本机满载 Q = 0.32（60V）～0.48（45.7V）
0.6 – 1.0平缓，峰值低峰值余量不足，重载时可能掉出感性区

注意 Q 不是常数——它随负载和输出电压变。设计时看的是满载最大功率点的 Q，本机是 60V/1600W 的 Q = 0.322（此时 Rac 最大、Q 最小），以及 45.7V/1600W 的 Q = 0.475。两个都要校核。

8.2　由 Z0 反解 Cr 和 Lr

Z0 = √(Lr/Cr) = 9.39 Ω　　　fr = 1/(2π√(Lr·Cr)) = 124.6 kHz
两式联立：
Cr = 1/(2π·fr·Z0) = 1/(2π×124.6e3×9.39) = 136 nF
Lr = Z0/(2π·fr) = 9.39/(2π×124.6e3) = 12.0 µH

正向设计时顺序是反的：先定 fr（受磁芯损耗和驱动能力约束，一般 100–150kHz 对 1600W 合适），再定 Z0（由选定的 Q 和 Rac 反推），然后才算出 Cr 和 Lr。本机是从 12µH / 136nF 反推出 fr = 124.6k，结果落在合理区间，说明原设计者的思路是对的。

8.3　为什么 fr 不能随便选

  • fr 太低（<100kHz）：60V 满载角点会撞到 60kHz 下限，磁通也上去了。本机如果 fr 降到 100k，60V/360V 角点只有 52kHz，磁通 0.56T，直接饱和。
  • fr 太高（>180kHz）：45.7V 满载角点会超过 250kHz 上限，而且开关损耗、驱动损耗上升，SR 时序窗口变窄（你的 M_ArHigh 表到 250kHz 就到头了，这不是巧合）。
  • 124.6kHz 的好处：60V 角点 65–83kHz，45.7V 角点 118–174kHz，42V 角点 153–205kHz，整个 PFM 区间 65–205kHz 落在固件 60–250kHz 限幅内，两侧都有余量。

10.1　原边电流

按 PQ4035 的 Ae ≈ 190mm² 估算，60V 满载角点的磁通在 0.42–0.45T。铁氧体在 100°C 时的饱和点通常 0.39–0.45T（PC95 约 0.39T，3C95 约 0.45T）。这个角点已经贴边，甚至可能超。

我无法确定实际 Ae 和材质，所以这条标 等级 D，必须实测/查规格书。三种可能：① 实际 Ae 更大（比如 250mm²），没问题；② 材质是高 Bs 的，勉强过；③ 确实超了，那 60V 满载在实物上是靠降额或提高 fr 规避的。

验证方法：绕 16T 测电感得 Al，反算 Ae；或直接看磁芯规格书。如果确实超，两条路——提高 fr（减 Cr 或 Lr，但会改变整个频率窗口）或增加 Np（改变 n，等于重新设计）。先确认，别先改。

11从频率到寄存器：软件怎么落地

这一章是你作为软件工程师的优势区，但有一个地方容易理解错，值得单独说。

11.1　量纲

preA = SHRTIMER_PLV / DriverPwm.Plv　　　SHRTIMER_PLV = 680,000,000
680MHz = 170MHz × 4（HRTIM 高分辨率倍频）。所以 preA 是计数值，Plv 是频率（Hz）。
fsw = 680e6 / preA　　→　fsw = 60kHz 时 preA = 11333，250kHz 时 preA = 2720

关键是 PI 的输出量纲：

Ctrl_interFace.flvOut = out * 50000.0f;　→　限幅 60000 ～ 250000　→　DriverPwm.Plv
PI 的输出直接就是频率（Hz）。这是 LLC 和 Buck 最本质的区别——Buck 调占空比，LLC 调频率。

所以你的 PI 参数、积分限幅、抗饱和，全都要按"频率"这个量纲来理解。比如积分项 piStructInter.integral = POW_MAX_PLV * 0.00002f，意思是"积分器预置在 250kHz 对应的位置"，这是抗饱和处理，不是随便写的数。

11.2　死区

LLC_DEADTIME = 120 counts　→　120 / 680e6 = 176 ns
注释写的是 300ns，已经过期。以实际值为准。

176ns 对 650V 器件、160pF 级 Coss 是合理的（ZVS 换流时间约 20–50ns，留 3–8 倍余量）。仿真模型里 dt = 150n，与实物接近，可以直接对比。

模型是别人给的，参数和你板子不完全一致（Cr 差 1.47 倍），但结构对。用对了能省几周时间，用错了会得到假结论。

两条曲线应该在中段吻合，在两端分叉：低频端仿真会偏低（FHA 忽略了高次谐波，而增益接近峰值时高次谐波贡献大），高频端仿真会偏高（FHA 假设纯正弦，实际电流断续）。这两个分叉的方向是固定的，记住它，你就知道什么时候该信仿真、什么时候该信计算。

12.2　LLC1600_PWM.plecs —— 定频模型

这个模型是定频 150kHz + 可调占空比（TriangleGenerator f=150k，DutyCycle=0.5；DT 子系统做死区）。它对应固件里 ConVolt / ConCurPWM 那几个分支（40k/80k/120k 定频、Duty 0.02–0.4）。

它的价值不是验证 LLC，而是验证"为什么这台机器要有两套控制律"。跑一遍你会看到：定频调占空比时，占空比从 0.5 降到 0.1，输出确实能降下来，但原边电流波形严重不对称、变压器偏磁、效率明显下降。所以它只能用在预充和过渡段，不能做主充电环路。

这一步的意义

你现在能解释固件里"为什么有两套控制律"了：不是因为写代码的人喜欢复杂，是因为 30–60V 的宽范围逼出了两套机制。PFM 覆盖 42–60V（ZVS、高效）；80kHz 对称 PWM 覆盖 30–42V（硬开关、效率低但能降压）；40kHz 开环 PWM 只管继电器预充。三者是接力关系，不是冗余。

能把这套逻辑讲清楚，你就不再是"看代码的人"，而是"能评价这套代码的人"。这是从 L3 走向 L2 的标志。

配套的 llc-gain-curve.html 已经把默认参数改成这台机器的实际值（n=4、Lr=12µH、Lm=80µH、Cr=136nF、Vo=50V、Po=1600W）。改参数时直接用那个工具，改完回这张表看影响面。

有一个小差异要知道：计算器按你填的 Po 直接算 Rac，本册表格按固件的 30A 限流算。50V 时 1600W 需要 32A，超过 30A 限值，所以两边差 3–4%（计算器给 83.2kHz，表 9-1 给 86.7kHz）。不影响结论，但对比数字时要知道差在哪。

14现在开始做的五件事

设计书看完了，接下来按这个顺序动手。前两件本周就能做完，不需要任何仪器。

注意：第 3 件和第 5 件都需要实机。在没有实机、只能用 PLECS 闭环仿真的条件下，完整路径见 LLC仿真打通_38周计划.html——它以 DLL 在环仿真替代实测，38 周打通整机与同步整流，实机作为最后验收。

  1. 改仿真模型，让它等于你的板子。把 C22 改成 136nF、V_dc2 改成 380V。这一步 10 分钟，但不做，后面所有对比都是错的。
  2. 跑一条增益曲线，和 FHA 叠在一起。扫 60k–250k，记录 Vo。看两条曲线在哪里分叉、分叉方向对不对。这是你第一次"用仿真验证理论"。
  3. 用 LCR 表实测三件事：Lr（拆下 L7 测）、Lm（副边开路测原边）、Cr（两只 68nF 是并是串，看 PCB 走线就能定）。测完把实际值填进计算器，看频率窗口有没有偏移。偏移多少，就是你对这台机器的理解误差。
  4. 确认 60V 满载的磁通。查 PQ4035 的 Ae 和材质 Bs，代进 §10.4 的式子。这是全机最紧的一项，也是最可能出问题的一项。
  5. 30–40V 段不用做 burst。80kHz 硬开关通路已经覆盖它（§5）。要做的是三件小事：① 扫 Duty–Vo 曲线，标定 0.02–0.4 的限幅；② 确认 40.2V 交接点有没有电压台阶（§5.6）；③ 量硬开关段 MOS 壳温，确认 3–13W 的 Coss 损耗撑得住。
最后一句

你这台机器的设计其实很干净：n=4 让 M=1 落在 50V，k=6.67 在"峰值够用"和"环流可接受"之间取平衡，fr=124.6k 让整个工作区落在 65–205kHz，固件用 60–250k 把它框住。每一处都能对上，没有拍脑袋的地方。

你要学的不是"再算一遍这些数"，而是这套判断是怎么做出来的——尤其是"用极端角点的可达性反证参数"和"用增益地板解释固件门限"这两个动作。这两个动作会跟着你一辈子，比任何一个具体数字都值钱。

本册所有数值由 FHA 基波近似计算，未含高次谐波、死区效应、器件压降。用于设计与校核，不替代样机实测。标注 UNK 的四项必须在打样前关闭。
