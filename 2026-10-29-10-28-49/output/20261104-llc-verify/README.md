# LLC 软启动验证套件

这个目录是用来**验证结论、留下证据**的，不是用来"跑个仿真看看波形"的。

## 文件

| 文件 | 作用 |
|---|---|
| `llc_verify.py` | 时域模型 + 12 个验证用例，跑一次自动出报告和图 |
| `out/report.md` | 自动生成的验证报告（含每条的判读） |
| `out/fig1~8.png` | 对应波形图（fig8 是 ZVS 的 U 形曲线） |
| `LLC软启动验证计划与记录台账.xlsx` | 验证计划（23 项）+ 测试记录（可填 40 条）+ 参数基线 + 结论台账 |
| `make_xlsx.py` | 台账生成脚本，改内容后重跑 |

## 怎么跑

```bash
pip install numpy matplotlib openpyxl
python llc_verify.py     # 约 2 分钟
python make_xlsx.py
```

## 改成你自己的参数

打开 `llc_verify.py`，只改 `P = dict(...)` 这一段：Vin、n、fr、Lr、Cr、Lm、Coss、Cout、Rload、fmax、fmin、dead。
**Coss 和 dead 必须填实测/手册值**，它们直接决定低端增益和窄脉冲能不能发出来。

改完重跑，报告里的所有数字都会跟着变。

## 三层验证，别跳级

| 层 | 工具 | 花多久 | 能回答什么 |
|---|---|---|---|
| L0 解析/脚本 | 这个目录 | 分钟 | 量程、趋势、比值、机理是否自洽 |
| L1 电路仿真 | PLECS / PSIM / Simulink | 小时 | 闭环行为、死区与 ZVS、损耗与结温 |
| L2 硬件 | 示波器 + 探头 | 天 | 一切。前两层只能缩小范围，不能下结论 |

**L0 的价值不是"证明我对"，而是"在你焊板子之前把错误结论筛掉"。**

## 三个会让你白干的仿真陷阱

1. **不建死区**。d=1%@200k 的 50ns 脉冲在理想模型里能正常输出，在实物上根本不开通。
2. **不建节点电容 Coss**。空档期中点会被硬钳位，波形变成干净的三电平脉冲——但实物上是梯形。
   这一条直接决定"低占空比增益有多低"，也是本模型误差最大的地方。
3. **整流器用电流符号模型**（`vp = n·Vo·sign(ip)`）。它允许变压器出现直流电压，
   违反伏秒平衡，会算出 Cr 稳态值偏离 Vin/2。必须用"导通/断开状态机 + 电压钳位"。

## 记录的四条规矩

1. **先写预期值，再看实测值**。否则你会不自觉地事后合理化。
2. **每个实验必须有对照组**。只测"30% 交接有振荡"不算证据，必须同时测"45% 交接不振荡"。
3. **记录偏差，不只是记录通过**。偏差 30% 的"通过"比偏差 2% 的"不通过"更有信息量。
4. **截图必须带文件名写进台账**，否则三个月后没人知道那张图是哪次测的。

## 本轮的结论（详见 out/report.md 的用例 11）

八条原始说法里，**五条被推翻，三条被修正，没有一条完全成立**。最终收敛成五条定理：

| # | 定理 | 关键数字 |
|---|---|---|
| 1 | 均值定理：对称 `mean(v_ab) ≡ Vin/2`，互补 `= d·Vin` | 实测偏差 < 1% |
| 2 | 互补基波定律：`\|V1\| = (2Vin/π)sin(πd)`，与负载无关 | 三种负载差 < 1% |
| 3 | 对称发波是闭环：`\|V1\|` 随电流变 | `d=0.05` 时差 43% |
| 4 | ZVS 是 U 形：两端都丢，中间才保住 | `d=0.25~0.40` 干净 |
| 5 | 可调范围不对称：对称 0.47~1.00，互补 0~1.00 | 选型硬判据 |

三条最要紧的：

- 小占空比不会偏磁饱和（Cr 自己隔直），代价是电流不对称 37.6% → 损耗不均；
- 对称发波的范围只有 **0.47~1.00**，`d>0.2` 就饱和，**它根本到不了低压**；
- 30% 交接的增益台阶只有 0.7%，**如果实测振荡，问题在频率环路，不在发波**。
