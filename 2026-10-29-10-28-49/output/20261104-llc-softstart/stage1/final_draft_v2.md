# 半桥 LLC 软启动：从增益曲线到工程实现（第二版）

> 本文以一台 1600 W 充电机的实际控制代码为样本，把 LLC 软启动的每一个决策都拆到"为什么必须这样"的层面。第二版根据大信号时域模型的验证结果，重写了发波机理部分：**半桥的中点不是理想开关，它在空档期是浮空的**，这一条改变了对称发波的全部结论。

## 第二版说明：这一版改了什么

第一版有一处推导错误，连带影响了四章的结论。错误不在结论的方向上，而在机理上——方向对了、机理错了，比全错更危险，因为你会照着错的机理去改电路。

### 六处修正

| 项 | 第一版 | 第二版 | 证据 |
|---|---|---|---|
| 对称发波基波 | `b1 = (4/π)·sin²(πd)`，30%→50% 是 1.53 倍 | 理想三电平的 `f` 分量**恒为零**，公式漏了一个负号 | 4096 点 FFT：`\|V(f)\| = 0.0000`，所有 d |
| d 的作用 | 0→0.5 的连续增益旋钮 | 只改变**波形形状**，不改变导通时间占比 | 中点均值恒为 0.500·Vin |
| 对称发波增益下限 | 趋于 0 | 约 0.55·`Mmin`，且**由 Coss 决定，不由 d 决定** | d=0.05 时 0.57，Coss 减到 0.3 nF 才降到 0.27 |
| 30% 交接台阶 | 1.53 倍，必然振荡 | 互补 1.16 倍，对称 1.02 倍 | 时域仿真，见 6.1 |
| `Cr` 直流工作点 | `Vcr = d·Vin` | 只对**互补**成立；对称下恒为 `Vin/2` | 互补 118.5 V（理论 120），对称 200.0 V |
| 振荡主因 | 增益台阶 | 台阶只是触发器，主因是**频率没有余量** | 模型 + 代码，见 6.2 |

### 错在哪一步

第一版算基波时写了这样一行：

```
b1 = (2/T)·[ ∫₀^{dT} sin(ωt)dt − ∫_{T/2}^{T/2+dT} sin(ωt)dt ]
   = (4/π)·sin²(πd)
```

第一个积分等于 `(T/2π)(1−cos2πd)`，第二个积分等于 **`−(T/2π)(1−cos2πd)`**——因为 `sin(ωt)` 在 `[T/2, T]` 区间是负的。所以方括号里是**两个相同的数相减**，结果恒为 0，不是 `(4/π)sin²`。

写成文字就是：**两个等宽、对称分布的脉冲，在一个周期里的基波分量精确抵消。** 这不是近似，是结构性的——波形的周期实际是 `T/2`，不是 `T`。

### 哪些结论没变

- 容性区在**低频侧**，不在低压侧（第 2、7 章）
- `Mmin` 是**量程下限**，不是稳定性问题（第 2 章）
- `Cr` 是隔直电容，稳态伏秒自动平衡（第 5、8 章）
- 1% 占空比在 200 kHz 下**物理上发不出来**（第 8 章）
- 抬 `fmax` 扩增益，代价是 ZVS 余量，`fs_max = 1/√(32·Lm·Coss)`（第 10 章）
- 企业工程用混合方案，理由是**补量程**，硬开关只是代价（第 9 章）
- 交接点必须落在 `d ≈ 0.45`，不能停在 30%，更不能停在 7%（第 6、7 章）

### 一句话

**第一版的结论基本没变，但"为什么"换了一套。** 而"为什么"决定你下一步改哪里——这就是必须重写的原因。

## 第 1 章 软启动到底在解决什么问题

### 1.1 如果直接给 50% 满占空比

把 LLC 从"停振"直接推到"50% 互补、工作频率"，会同时发生三件事：

1. **输出电容充电电流失控。** 输出从 0 V 起充，误差放大器饱和，环路要求最大增益，频率一路压到下限。此时原边电流只受谐振腔阻抗限制。
2. **第一次开关就是硬开关。** 起机瞬间谐振腔里没有电流，MOS 的结电容是满电荷状态，第一个脉冲打上去就是 400 V 硬开通。
3. **`Cr` 的初始电压是 0，不是 `Vin/2`。** 稳态时 `Cr` 上的电压由发波方式决定（第 5 章给出精确表达式），但上电瞬间它是 0。前几十个周期里，加在变压器上的正负伏秒严重不平衡。

模型给出的量级：稳态原边电流峰值 3.10 A，而第一个周期的峰值是 **10.49 A**，是稳态的 **3.38 倍**，之后第 5 周期 8.05 A、第 20 周期 4.35 A，逐步回落。

**冲击不是"电压高"造成的，是"`Cr` 从 0 充到 `Vin/2` 这段路上，多出来的电荷全部要从原边灌进去"。** 软启动要压的就是这一段，而不是稳态。

### 1.2 软启动的三个目标

| 目标 | 物理量 | 判据 |
|---|---|---|
| 电流可控 | 原边谐振电流峰值、输出充电电流 | 不超过额定 1.2 ~ 1.5 倍 |
| 磁通可控 | 每半周伏秒积 | 正负对称，无直流偏置累积 |
| 损耗可控 | 开关损耗、`dv/dt` | 尽量全程 ZVS，边沿不产生采样干扰 |

注意第一条和第三条之间有冲突：要压电流就得慢，但慢意味着高频运行时间变长，驱动损耗累积。10 ~ 50 ms 这个经验区间就是这么来的。

### 1.3 两个旋钮不是平级的

LLC 有两个可调量：开关频率 `f` 和占空比 `d`。很多人下意识把它们当成"两个平级的旋钮"，可以互相替补。**这个直觉是错的，而且第二版比第一版更坚决。**

- 频率是**连续、无损、保 ZVS** 的旋钮，但调节范围有硬边界（`Mmin` 到 `Mmax`）。
- 占空比是**粗调、有损、丢 ZVS** 的旋钮，它的唯一价值是**突破 `Mmin` 下限**。

第二版要补一句：**占空比这个旋钮的"刻度"在两种发波方式下完全不同。** 互补发波下，它是一条干净的 `sin(πd)` 曲线，你可以放心当衰减器用；对称发波下，它的刻度是糊的——增益下限由 `Coss` 决定，不由 `d` 决定。第 3、4、5 章专门讲这件事。

## 第 2 章 先画地图：LLC 的增益曲线

### 2.1 基波近似（FHA）增益公式

忽略谐波，只取开关频率处的基波分量，半桥 LLC 的归一化增益为：

```
M(fs) = 1 / sqrt( [1 + Ln·(1 - (fr/fs)²)]² + [Q·(fs/fr - fr/fs)]² )
```

其中：

```
Ln = Lm / Lr                        （电感比，典型 3 ~ 10）
Zr = sqrt(Lr / Cr)                  （特征阻抗）
Q  = Zr / Rac                       （品质因数，Rac = 8n²Vout²/(π²Pout)）
fr = 1 / (2π·sqrt(Lr·Cr))           （谐振频率）
```

三条必须记住的性质：

1. **`fs = fr` 时 `M = 1`。** 这是增益曲线的"锚点"。
2. **`fs` 升高，`M` 单调下降。** 这就是 PFM 调压的全部依据。
3. **`Q` 越大（负载越重），峰值增益越低。** 所以最恶劣工况是"满载 + 最低输入电压"。

**一个符号约定必须先钉死：FHA 的 `M` 定义为 `M = 2n·Vo/Vin`，所以**

```
Vo = M · Vin / (2n)
```

少写这个 2 会让输出电压差一倍。这是这份文档里最容易犯、也最难发现的错。

### 2.2 容性区到底在哪一侧

这是最常被搞反的一件事。

增益曲线有一个峰值点 `fpeak`。`fpeak` **左侧**（频率更低、增益更高）是**容性区**：谐振腔输入阻抗呈容性，电流**超前**电压。`fpeak` **右侧**是**感性区**：电流**滞后**电压，滞后的电流在死区里帮管子抽干结电容，才有 ZVS。

由此推出两条反直觉但正确的结论：

- **输出电压越低，需要的增益越低，工作频率越高，工作点越往右，越深入感性区。** 所以低压侧是整条曲线上最安全的一段。
- **容性区只会在"环路把频率压到 `fpeak` 以下"时进入**，也就是"增益需求超过了当前 Q 下的峰值增益"。触发条件是电流太大（输出短路、输出电容太大、启动充电太猛），不是电压太低。

### 2.3 Mmin：LLC 的量程下限

频率不可能无限升高。受死区占比、驱动损耗、ZVS 余量三重限制，工程上一定有一个 `fmax`。`fmax` 处的增益就是 `Mmin`，它对应的输出电压就是**这台 LLC 用调频能产生的最低电压**。

```
Vout_min(PFM) = Mmin · Vin / (2n)
```

低于这个电压，**频率调到无穷大也降不下去**。这不是稳定性问题，是**量程问题**——就像用只能读到 0 的秤去称负数。

想把 `Mmin` 压低，只有三条路，每条都有代价：

| 手段 | 效果 | 代价 |
|---|---|---|
| 提高 `fmax` | `Mmin` 下降 | 死区占比变大、驱动损耗上升、ZVS 余量按 `1/f²` 衰减 |
| 增大 `Ln`（加大 `Lm`） | 曲线整体下移、范围变宽 | 峰值增益和带宽变化，需重算 |
| 增加第二个旋钮（占空比 / burst） | 突破 `Mmin` 限制 | 丢 ZVS、增 EMI |

### 2.4 三个必须记住的频率，和一次模型自检

```
fpeak   —— 增益峰值点，容性区与感性区的分界，绝不能越过
fmax    —— 最高工作频率，决定 Mmin
fmin    —— 最低工作频率，决定 Mmax，通常取 1.2 ~ 1.5 倍 fpeak 以上留余量
```

工程上必须做的一件事：**给 `fmin` 设硬钳位，位置在"最恶劣 Q 下的 `fpeak`"之上，留 10% 余量。** 这一条比任何发波技巧都更能防容性区。

拿工具下结论之前，先证明工具可信。时域模型与 FHA 解析的对比：

| f (kHz) | FHA 预测 | 时域仿真 | 偏差 |
|---|---|---|---|
| 100 | 12.50 V | 12.58 V | +0.7% |
| 130 | 8.04 V | 8.73 V | +8.5% |
| 160 | 6.72 V | 7.28 V | +8.3% |
| 200 | 5.91 V | 6.27 V | +6.1% |
| 250 | 5.33 V | 5.51 V | +3.3% |

**`fn = 1` 处只差 0.7%，`fn = 1.3 ~ 2.5` 差 3 ~ 9%。** 偏差来自死区、二极管压降和谐波。结论：**FHA 用来判量程够不够，用来定精确工作点不够。**

## 第 3 章 中点电压到底由谁决定

这一章是第二版新增的，也是整篇文档的地基。第一版之所以算错，就是因为默认了"开关管一关断，中点就回到 0"。

### 3.1 一个被默认掉的假设

教科书分析半桥时，`v_ab` 被画成一个干净的两电平方波：上管通 `Vin`，下管通 `0`。这个画法隐含了一个假设——**中点总有一根管子把它硬拽到某个轨上**。

互补发波时这个假设成立：任何时刻不是上管通就是下管通（除了死区）。

**但对称发波时它不成立。** 两个脉冲之间那段空档里，上下管**都关断**，中点是一根悬空的线，没有任何东西决定它的电压。

### 3.2 中点浮空：`v_ab` 是电流的积分

空档期，中点上只挂着电容 `C_node = 2·Coss`（两个管的输出电容并联，加一点寄生），而谐振电流 `i_Lr` 必须从这个节点流进谐振腔。于是：

```
C_node · dv_ab/dt = −i_Lr
```

即：

```
v_ab(t) = v_ab(t₀) − (1/C_node) · ∫ i_Lr dt
```

**中点在空档期不是被钳位，是在对电流做积分。** 这句话是整个第二版的核心。

它带来两个直接后果：

1. **波形形状由电流决定，不由栅极决定。** 你给的是"两个 5% 的窄脉冲"，出来的可能是一条缓慢的三角波。
2. **过渡需要时间。** 把中点从 0 抬到 `Vin`，需要的电荷是 `Q = C_node·Vin`，时间约为：

```
t_slew ≈ C_node · Vin / |i_Lr| = 2·Coss·Vin / |i_Lr|
```

### 3.3 过渡时间有多长

用示例参数算：`Coss = 1.5 nF`，`C_node = 3 nF`，`Vin = 400 V`，需要电荷 `1.2 µC`。

| 原边电流 | `t_slew` | 占周期比（200 kHz，T=5 µs） |
|---|---|---|
| 0.9 A | 1.33 µs | 27% |
| 3.0 A | 400 ns | 8% |
| 10 A | 120 ns | 2.4% |

**电流越小，中点越"赖着不走"。** 这一点极其关键，因为它和软启动的处境正好撞上：启动初期电流本来就小。

### 3.4 三种波形形态

把 `t_slew` 和空档长度 `(0.5−d)·T` 一比，就得到三种形态：

| 条件 | 波形 | 后果 |
|---|---|---|
| `t_slew << (0.5−d)T` | 中点快速过渡，然后在轨上**停住** → 真三电平 | 空档里真有 0 电平。此时主导谐波在 `2f`，增益很低 |
| `t_slew ≈ (0.5−d)T` | 中点一直在爬 → **梯形 / 三角** | 增益由电流决定，`d` 几乎不起作用 |
| `t_slew >> (0.5−d)T` | 中点几乎不动 → 空档被"填平" | 退化成 **50/50 方波**，增益等于满增益 |

第三种情况最反直觉：**空档太短，中点还没来得及动，下一管就开通把它拽回去了，于是空档等于不存在。** 这就是为什么 `d = 0.45` 和 `d = 0.5` 的波形几乎一样。

### 3.5 用数据看这三种形态

对称发波，逐周期统计中点电压处于"中间态"（既不在 0 也不在 `Vin`）的时间占比：

| d | 中间态占比 | 高电平占比 | `v_ab` 均值 / Vin | Vout |
|---|---|---|---|---|
| 0.05 | **88.1%** | 5.9% | 0.499 | 3.55 V |
| 0.10 | 53.8% | 23.3% | 0.501 | 4.77 V |
| 0.20 | 20.6% | 39.7% | 0.500 | 6.15 V |
| 0.30 | 16.2% | 42.0% | 0.501 | 6.24 V |
| 0.45 | 9.5% | 45.2% | 0.499 | 6.27 V |

这张表把第 3 章的全部内容量化了：

- `d = 0.05` 时，**88% 的时间中点在中间漂着**，波形是三角波，不是脉冲串；
- `d = 0.45` 时，中间态只剩 9.5%，波形已经是方波；
- **`v_ab` 的均值在所有 `d` 下都是 0.500·Vin**——不是 `d·Vin`，不是 `2d·Vin`，就是一半。

最后这一条最重要，第 4 章会用它推出全部结论。

## 第 4 章 对称发波：为什么它不能当增益旋钮

### 4.1 理想三电平的频谱：基波恒为零

先算一个纯数学问题：如果中点真的被钳住，波形是"两个等宽脉冲，居中于 `T/4` 和 `3T/4`"，它的频谱是什么？

不用积分，看对称性就够了：`v(t + T/2) = v(t)`。第二脉冲正好落在第一脉冲平移半个周期的位置。**波形周期实际是 `T/2`，不是 `T`。** 所以：

- 直流分量：`2d·Vin`
- `f` 分量：**精确为零**
- `2f` 分量：`(2/π)·sin(2πd)·Vin`
- 三次及以上奇次：零

4096 点 FFT 验证（已去均值）：

| d | `\|V(f)\|` | `\|V(2f)\|` | `\|V(3f)\|` | 均值 |
|---|---|---|---|---|
| 0.05 | **0.0000** | 0.1969 | 0.0000 | 0.100 |
| 0.20 | **0.0000** | 0.6054 | 0.0000 | 0.400 |
| 0.30 | **0.0000** | 0.6054 | 0.0000 | 0.600 |
| 0.45 | **0.0000** | 0.1969 | 0.0000 | 0.900 |

**`f` 分量在所有 `d` 下都是 0.0000。** 这就是第一版那个 `sin²(πd)` 错在哪里的最终证据。

顺带一个自我检查：这张表说 `d = 0.5` 时均值是 1.0（纯直流）、交流分量全为零——也就是"没有输出"。这显然荒谬。**荒谬本身说明这个理想模型在 `d → 0.5` 处失效**，因为它要求中点被钳住，而 `d = 0.5` 时空档为零、上下管直通。所以这个模型只能当参考，不能当设计依据。

### 4.2 真实的对称发波：波形在变，增益在下限

真实电路里中点浮空（第 3 章），所以波形既不是理想三电平，也不是窄脉冲，而是随 `d` 从三角波渐变到方波。实测增益：

| d | 0.05 | 0.10 | 0.20 | 0.30 | 0.45 | 50/50 |
|---|---|---|---|---|---|---|
| Vout | 3.55 V | 4.77 V | 6.15 V | 6.24 V | 6.27 V | 6.27 V |
| 相对满增益 | **0.567** | 0.761 | 0.981 | 0.995 | 1.000 | 1.000 |

**`d = 0.2` 就到了 98%，之后加占空比什么都不会变。**

更值得注意的是下限：`d = 0.05` 时增益还有 0.57，也就是说**你把占空比压到 5%，输出也只掉到一半，掉不到零**。

### 4.3 下限由 Coss 决定，不由 d 决定

这是第二版最重要的一个新结论。把 `Coss` 换成三档重跑：

| Coss | d=0.05 | d=0.10 | d=0.20 | d=0.30 | d=0.45 | 50/50 |
|---|---|---|---|---|---|---|
| 0.3 nF | 1.72 V（0.27） | 2.41 V | 3.91 V | 6.27 V | 6.27 V | 6.27 V |
| 1.5 nF | 3.50 V（0.56） | 4.74 V | 6.13 V | 6.23 V | 6.25 V | 6.27 V |
| 4.0 nF | 4.01 V（0.64） | 4.39 V | 5.10 V | 5.88 V | 6.26 V | 6.27 V |

`d = 0.05` 的增益从 0.27 变到 0.64，**而 `d` 一点没变**。变的是 `Coss`——也就是 `t_slew`。

**为什么 d 压不下去？** 因为这里有一个自限机制：

```
d 减小 → 空档变长 → 中点有时间漂移 → 波形变成三角波 → 增益下降
      → 但增益下降导致电流减小 → t_slew 变长 → 中点漂得更慢
      → 波形反而更接近方波 → 增益回升
```

两个方向互相抵消，最后停在一个由 `Coss`、`Vin`、`i` 决定的位置。**`d` 只是在这个位置上做微调。**

### 4.4 它的两个真优点

对称发波不是一无是处，它有两个互补发波没有的性质：

**（1）`Cr` 恒在 `Vin/2`，没有充电瞬态。**

`v_ab` 的均值在所有 `d` 下都是 0.500·Vin（3.5 节表格）。因为稳态下 `Cr` 的电压必须等于 `v_ab` 的均值（否则初级电流会有直流分量），所以 `Cr` 从头到尾稳在 `Vin/2`。

**这意味着对称发波的整个爬坡过程里，`Cr` 不需要充电，没有额外的电荷注入。** 而互补发波要（第 5 章）。

**（2）两管导通时间严格相等，损耗均衡。**

互补发波在 `d ≠ 0.5` 时，两个管子的导通时间一个长一个短，电流波形也一个峰高一个峰低。对称发波没有这个问题。

### 4.5 结论：它是波形整形，不是增益旋钮

| 用途 | 能不能用 |
|---|---|
| 当增益旋钮做软启动 | **不能**。刻度糊、下限由 `Coss` 定、增益随负载漂移 |
| 在窄增益带内做平滑过渡 | **可以**。企业工程就是这么用的（第 9 章） |
| 避免 `Cr` 充电瞬态 | **这是它最大的价值** |

## 第 5 章 互补发波：d 才是干净旋钮

### 5.1 波形

上管导通 `d·T`，下管导通 `d·T`，中间各留一段死区。因为只有两个脉冲、且分居半周期的两端，`v_ab` 是一个真正的两电平波形，占空比就是 `d`。

**关键区别：互补发波下中点任何时刻都被某根管子（或体二极管）钳住，不存在浮空期。** 所以第 3 章那套"积分"分析在这里不适用，波形由栅极决定，可重复。

### 5.2 增益 ∝ sin(πd)

两电平波形，占空比 `d`，基波幅值 `(2Vin/π)·sin(πd)`。实测（`f = 200 kHz`，`Rl = 0.36 Ω`）：

| d | 0.05 | 0.10 | 0.20 | 0.30 | 0.45 | 0.50 |
|---|---|---|---|---|---|---|
| Vout | 1.33 V | 2.54 V | 4.36 V | 5.39 V | 6.22 V | 6.27 V |
| 相对满增益 | **0.213** | 0.406 | 0.695 | **0.859** | 0.991 | 1.000 |
| `sin(πd)` | 0.156 | 0.309 | 0.588 | 0.809 | 0.988 | 1.000 |

实测值系统性略高于 `sin(πd)`（`d` 小时差 37%，`d ≥ 0.3` 时差 6% 以内），因为增益不是基波的线性函数，还叠加了谐振腔在不同频率点的传输特性。**但趋势和量级完全对得上：`d = 0.3` 时是 0.86，跳到 0.5 是 1.16 倍。**

这就是我在最早那次回答里说的"24%"，而不是第一版文档里的"1.53 倍"。

### 5.3 Cr = d·Vin，这是真的

互补发波下，`v_ab` 的均值就是 `d·Vin`，所以：

```
Vcr = d · Vin
```

实测 `d = 0.3` 时 `Cr` 平均电压 **118.5 V**，理论 120 V，纹波 86 Vpp。**误差 1.3%，公式可用。**

对比对称发波：`Cr` 恒为 200.0 V（`Vin/2`），跟 `d` 无关。同一个公式套上去会差 40%。

**所以第一版那条"`Vcr = d·Vin`"没有全错，它只是漏了适用条件。** 写公式不写适用范围，比写错公式更坑人。

### 5.4 代价：三样

| 代价 | 实测 / 机理 | 量级 |
|---|---|---|
| 电流不对称 | `d = 0.3`：正峰 3.48 A / 负峰 −2.17 A | **差 37.6%** |
| 硬开关 | 空档期电流走体二极管，中点被钳位，下管开通时面对满电荷 `Coss` | 16 W 量级 |
| `Cr` 偏置 | 从 0 充到 `d·Vin`，爬坡过程中一直在充 | 额外电荷注入 |

电流不对称这一条要展开说：**两个管子的电流应力差 37.6%，意味着损耗差、温升差。** 长期在 `d = 0.3` 下跑，两个管子壳温差 10 ℃ 以上是正常的。这也是为什么占空比只能当"短时粗调"，不能当稳态工作点。

### 5.5 一个反直觉的事实：磁通摆幅 ∝ d

```
ΔB = (Vin/2) · d · T / (N · Ae)
```

`d` 越小，磁通摆幅越小，峰值磁通越低。**小占空比不但不会更容易饱和，反而离饱和更远。**

真正会出现伏秒不等的是另一种工况：**脉冲宽度掉到跟死区、驱动传输延迟同一个量级**。这时两个半周的实际导通时间不再相等（一个被最小脉宽截断，一个被体二极管续流补掉），才出现真正的偏磁。这不是"小占空比必然饱和"，是"脉宽太窄必然失控"。

## 第 6 章 30% 跳 50% 为什么会振荡

### 6.1 先把台阶算准

第一版说"1.53 倍，必然振荡"。实测：

| 发波方式 | 30% 时的增益 | 跳到 50% 后 | 台阶 |
|---|---|---|---|
| 互补 | 0.859 | 1.000 | **1.16 倍** |
| 对称 | 0.995 | 1.000 | **1.005 倍** |

**台阶比你想象的小得多。** 尤其对称发波——`d = 0.3` 时波形已经基本等于 50/50，跳过去几乎没有变化。

所以：**如果你的硬件上 30% 交接真的振荡了，主因不是占空比台阶。**

### 6.2 主因：频率没有余量

台阶只是触发器，真正让它变成持续振荡的是**频率已经顶到上限**：

```
现象：30% 占空比就到达目标电压
推理：50% 占空比 + fmax 下的增益已经超过目标
结论：要把增益压回去，频率必须高于 fmax —— 而 fmax 就是上限
```

于是环路看到过冲，把频率往上推，推到 `fmax` 顶死，进入积分限幅；输出掉下来，环路再往回拉。来回就是极限环。

**你实际上是在用占空比当"额外的降压旋钮"，去补频率上限不够的那部分增益。稳态能凑合，但一旦要把这个旋钮交还给频率，就必然出现台阶。**

这一条第一版就说了，第二版确认它仍然是主因。判断方法很简单：**交接瞬间抓频率指令，看它有没有在 `fmax` 上贴住不动。** 贴住了，就是它。

### 6.3 第二个来源：Cr 偏置跳变（只对互补发波）

互补发波下 `Vcr = d·Vin`。`d` 从 0.30 跳到 0.50，`Cr` 要从 `0.3·Vin` 充到 `0.5·Vin`，**多出 0.2·Vin × Cr 的电荷**，这些电荷要从原边灌进去。输出会再冲一下，磁通也走一段。

对称发波没有这一项，因为 `Cr` 全程都在 `Vin/2`。

### 6.4 第三个来源：增益随负载漂移（只对对称发波）

这是第二版新发现的，也是对称发波最阴的地方。

第 4.3 节说过：对称发波的增益下限由 `t_slew = 2·Coss·Vin/i` 决定。而 `i` 是负载电流。所以：

```
同一个 d，空载时增益 X，满载时增益 Y，X ≠ Y
```

**这意味着"d = 30% 对应 12 V"这句话本身不成立**——它只在某个特定负载下成立。负载一变，同一个 `d` 给出的电压就变了。

于是启动过程变成：`d` 按固定斜率爬，但增益随电流变化，输出不是单调上升；环路看到电压不对，去调频率；频率又在 `fmax` 上顶死……这就是"每次都不同"的来源。

**这条可以解释为什么你的启动现象不可重复。** 如果现象可重复，问题在发波；如果每次都不一样，问题在"增益本身不是 `d` 的函数"。

### 6.5 三个波形判据，一眼分辨是哪一种

| 抓什么 | 看到什么 | 结论 |
|---|---|---|
| 频率指令 | 交接后贴在 `fmax` 不动 | 频率无余量（6.2） |
| `Cr` 电压 | 交接瞬间有台阶式上升 | `Cr` 偏置跳变（6.3） |
| 同一 `d` 下不同负载的 Vout | 数值不同 | 增益随负载漂移（6.4） |

### 6.6 正确解法

**方案 A（输出范围窄时首选）：纯扫频，占空比从头到尾 50/50。**

- 起始频率取 1.2 ~ 1.5 倍 `fmax`，50/50 互补，死区照常
- 频率按 S 曲线或指数从 `fstart` 扫到 `f_op`，10 ~ 50 ms
- 增益从 `Mmin` 平滑升到目标，全程 ZVS
- 配逐周期限流 + Vref 软启动（让环路追一个缓慢上升的基准）
- **前提是 `Mmin(fmax) < Mtarget`，并留 10 ~ 15% 余量**

**方案 B（输出范围宽、确实需要低于 `Mmin`）：两段式，用互补发波做 A 段。**

- A 段：频率钉在 `fmax`，`d` 从 0.05 爬到 `0.5 − t_dead/T`，增益 0.21 → 1.00
- B 段：`d` 固定 0.5，频率从 `fmax` 扫到 `f_op`，增益 `Mmin` → 目标
- 交接点在 `(d_max, fmax)`，**此时波形就是 PFM 在 `fmax` 处的波形，零台阶**

**为什么 A 段要用互补而不是对称？** 因为你需要的是"从 0 到 `Mmin` 的连续可调"，互补给你 0.21 → 1.00 的干净曲线；对称只给你 0.55 → 1.00，而且刻度糊。**需要宽范围就用互补，需要无 `Cr` 瞬态就用对称，两者不能兼得。**

**方案 C（控制器改不了，只能做对称占空比软启动）：把目标定在窄带内。**

- 只在你确实只需要 1.3 倍左右增益带的时候用（企业工程就是这么用的）
- 爬坡形状用 `1−cos`，末段天然平缓
- 必须实测 M–d 曲线，不能靠算

## 第 7 章 7% 到 12V 再切 50%：为什么不保险

### 7.1 容性区在低频侧，不在低压侧

前面已经证明：输出电压越低 → 需要增益越低 → 频率越高 → 工作点越靠右 → **越深入感性区**。

所以 0 ~ 12 V 恰恰是整条曲线上**最安全**的一段。担心"低压启动容易进容性区"，是把容性区的位置记反了。

### 7.2 0 ~ 12 V 的真正问题是"够不着"

如果你的设计里 `fmax` 对应 12 V，那意味着 `Mmin` 对应 12 V。50% 占空比下，环路会顶在频率上限，输出停在 12 V 下不去——这是**量程不够**，不是稳定性问题。

用占空比降压，本质是在补量程，这个思路本身没错。错的是补的方式。

### 7.3 7% 交接：台阶是 3.4 倍，而且暴露了一个更严重的问题

互补发波下 `d = 0.07` 的增益约 0.29（在 0.213 和 0.406 之间插值），跳到 0.5 是 **3.4 倍**。不是第一版说的 21 倍，但仍然是"必然过冲"的量级。

**更严重的是这个数字反推出来的结论**：如果 `d = 0.07` 就给到 12 V，那 50% 占空比 + `fmax` 会给到 `12 / 0.29 ≈ 41 V`。**也就是说你这台机器的 `Mmin` 是 41 V，不是 12 V。**

这意味着：

- 你的 12 V 目标在 `Mmin` 之下 3.4 倍处，**完全靠占空比压下来**；
- 一旦把旋钮交还给频率，频率最低只能到 `fmax`，输出立刻往 41 V 冲；
- 环路只能靠 OVP 或限流救场。

**所以这个方案的问题不是"切换太突然"，是"你根本没有可交接的点"。** 12 V 这个工作点在 PFM 的调节范围之外。

### 7.4 先做一件事：测出你自己的 M–d 曲线

在讨论"能不能这样切"之前，必须有一个数：

> 固定 `f = fmax`，让 `d` 从 0 扫到 0.5（互补），记录 `Vout`。

判读方法：

- 如果 `d = 0.07` 给 11.8 V、`d = 0.5` 给 12.2 V → 占空比旋钮在 7% 就饱和了（对称发波常见），这个方案没有意义
- 如果 `d = 0.07` 给 12 V、`d = 0.5` 给 41 V → 说明 12 V 在 `Mmin` 之下，必须重新设计谐振腔或匝比
- 如果 `d = 0.07` 给 3 V、`d = 0.5` 给 12 V → **这是唯一能正常交接的情况**，交接点正好落在 `Mmin` 上

这个数不测出来，所有讨论都是猜。**而且必须用互补发波测**——用对称发波测出来的曲线没有意义（第 4 章）。

### 7.5 让 12 V 自己出现在交接点上

如果 `Mmin(fmax)` 恰好对应 12 V，那就别停在 7%：

1. `f` 固定在 `fmax`，`d` 从 0.05 爬到 `d_max`，`Vout` 从 0 升到 12 V
2. `d = d_max` 的那一刻，`Vout` 正好在设计点上，**这就是交接点，台阶为零**
3. 然后 `d` 固定 0.5，`f` 从 `fmax` 扫到 `f_op`，`Vout` 从 12 V 升到 24 V

**占空比要爬到最大，不是停在 7%。** "升到 12 V 才开始调频"这个直觉是对的，因为 12 V 就是频率调不动的下限；错的是"怎么到 12 V"。

### 7.6 真正防容性区的三件套

跟占空比无关：

1. **最低频率硬钳位**：设在最恶劣 Q 下的 `fpeak` 之上，留 10% 余量
2. **逐周期限流**：限制原边或副边电流峰值
3. **Vref 软启动**：让环路追一个缓慢上升的基准，别让它一上来就要求满增益

启动时最容易把环路逼进容性区的，是**输出电容太大、充电电流太大**——Q 一高，峰值增益掉下来，环路一路往下压，压过 `fpeak` 就进去了。该防的是"电流太大"，不是"电压太低"。

## 第 8 章 1% 占空比能不能发出来

### 8.1 三个时间尺度

窄脉冲能不能成立，取决于它和这三个量谁大：

| 量 | 典型值 | 说明 |
|---|---|---|
| 死区 `t_dead` | 150 ~ 300 ns | 防止直通，必须留 |
| 驱动传输延迟差 | 50 ~ 150 ns | 光耦/隔离驱动的上升沿延迟 |
| MOS 完全开通时间 | 100 ~ 300 ns | 含密勒平台 |

### 8.2 算一遍

以 200 kHz、`d = 1%` 为例：

```
T     = 1 / 200k = 5 μs
脉宽  = 5 μs × 1% = 50 ns
死区  = 150 ns
```

**50 ns 比死区还短。** 这个脉冲物理上发不出来——它会被死区逻辑吃掉，或者被驱动器的最小脉宽限制截断，或者 MOS 根本来不及进入低阻区。

时域模型直接给出 `Vout = 0.000 V`：上管被死区完全吃掉，一个脉冲都没发出去。

再看企业工程：`SHRTIMER_MIN_DUTY = 0.05`，250 kHz 下 5% = **200 ns**，而 `LLC_DEADTIME = 120` 计数 @ 680 MHz = **176 ns**。

**他们选的起点正好卡在"脉宽 ≈ 死区"这条线上，一步都不往下走。** 这不是保守，这是物理下限。

### 8.3 一个必须提醒的仿真陷阱

如果模型里不建死区，这个 50 ns 脉冲会正常出现、输出也正常——**仿真会骗你**。做这类验证，死区必须建模，而且必须和真实驱动器的传输延迟对齐。

### 8.4 结论

- 占空比下限不低于 **10%**，并用电流探头确认实际栅极波形
- 如果必须更窄，说明你的 `Mmin` 设计有问题，应该改谐振腔参数，而不是硬压脉宽

## 第 9 章 拆解一份企业级工程

### 9.1 规格

| 项 | 值 | 出处 |
|---|---|---|
| 输出功率 | 1650 W | `OUTPUT_POW_MAX` |
| 输出电流 | 30 A | `OUTPUT_CUR_MAX` |
| 待机保持电压 | 30 V | `CON_VOLT_OUT` |
| 最高电池电压 | 58 V | `MAX_BAT_VOLT` |
| 过压保护 | 65 V | `HW_VOLT_OVP` |
| 最高频率 | 250 kHz | `POW_MAX_PLV` |
| 最低频率 | 60 kHz | `POW_MIN_PLV` |
| 死区 | 120 计数 ≈ 176 ns | `LLC_DEADTIME` |
| 定时器时钟 | 680 MHz | `SHRTIMER_PLV` |
| 快环频率 | 40 kHz | `POW_INT_PLV` |

注意输出范围是 **0 ~ 58 V**，而 LLC 的 PFM 只能覆盖其中一段。这个"范围不匹配"就是整个设计的出发点。

### 9.2 四段式状态机

```
SoftStar → BmsStar → SoftCurSt → ConVolt → ConCurPWM → Transition → OvLoadPFM
                                                        ↑
                                              真正的"软启动"在这里
```

| 模式 | 发波 | 覆盖区间 | 任务 |
|---|---|---|---|
| `ConVolt` | 120 kHz 定频，`d = 1% ~ 15%` | 0 ~ 30 V | 把 LLC 当 buck 用，硬顶 |
| `Transition` | 250 kHz 钉死，`d = 0.05 → 0.449`，10 ms | 30 V → `Mmin` | **补量程，不是软启动** |
| `OvLoadPFM` | `d = 0.5`，`f = 250k → 60k` | `Mmin` → 58 V | 正常工作 |

**这张表是全篇的钥匙。** 它说明：`Transition` 那一段的存在理由，不是"要慢慢启动"，而是"30 V 到 `Mmin` 这一段频率够不着"。

### 9.3 发波实现

关键在 `SHRTIMERdrive()`。周期寄存器是 `pre = 680MHz / f`，然后按模式分两套 CMP：

```c
/* 周期寄存器：680MHz 定时器时钟 / 目标频率 */
pre  = 680000000.0f / DriverPwm.Plv;

if (CtrMode != OvLoadPFM) {
    /* ---- 对称发波：脉冲居中于 T/4 与 3T/4 ---- */
    temp  = pre >> 2;                    /* T/4 */
    bemp  = pre - temp;                  /* 3T/4 */
    time1 = ((float)half) * DriverPwm.Duty;
    duty  = (uint16_t)time1;             /* 半宽 = T·d/2 */

    CMP1 = temp - duty;                  /* 脉冲 1 前沿 */
    CMP2 = temp + duty;                  /* 脉冲 1 后沿 */
    CMP3 = bemp - duty;                  /* 脉冲 2 前沿 */
    CMP4 = bemp + duty;                  /* 脉冲 2 后沿 */
} else {
    /* ---- 互补发波：50/50 + 固定死区 ---- */
    CMP1 = LLC_DEADTIME;
    CMP2 = half - LLC_DEADTIME;
    CMP3 = half + LLC_DEADTIME;
    CMP4 = pre  - LLC_DEADTIME;
}
```

注意 `duty` 是**半宽**，所以脉冲总宽度是 `T·d`，两个脉冲加起来正好是 `2d·T`，空档 `(1−2d)·T`。

### 9.4 交接逻辑

```c
case Transition:
    DriverPwm.Plv  = POW_MAX_PLV;              /* 250 kHz，钉在最高频 */
    DriverPwm.Duty = time * 0.001f + 0.05f;    /* 0.05 → 0.45 */
    if (time >= 400) {                          /* 40 kHz × 400 = 10 ms */
        piStructInter.integral = POW_MAX_PLV * 0.00002f;
        Ctrl_interFace.CtrMode = OvLoadPFM;
    }
    break;

case OvLoadPFM:
    flvOut = PI输出 * 50000.0f;
    if (flvOut > POW_MAX_PLV) { flvOut = 250000; integral = 250000 * Ki; }
    if (flvOut < POW_MIN_PLV) { flvOut =  60000; integral =  60000 * Ki; }
    DriverPwm.Duty = 0.5f;
    break;
```

A 段 `f` 钉在 `fmax`、`d` 从 5% 爬到 45%（10 ms）；交接点 `(0.45, 250 kHz)`；B 段 `d = 0.5`、`f` 从 250 kHz 往下扫。

**注意 A 段全程不读 `Vout`。** `time` 只是 40 kHz 中断里的计数器，数到 400 就切，此时 `Vout` 是多少就是多少。这不是疏忽，是刻意的——按固定时间爬换来的是可重复性，代价是放弃"刚好到点就停"这种精度。而 B 段入口必须给 PI 积分器一个确定初值（`integral = fmax × Ki`），这个初值只有在交接状态确定时才有意义。

### 9.5 为什么它敢用对称发波：因为只需要 1.3 倍增益带

这是第二版修正的最重要一处解读。

第一版说"它选 0.45 是因为 0.45 已经等于 50/50，交接零台阶"。这句话对，但没说清为什么敢用对称发波这种"刻度糊"的方案。

真正的理由是**它不需要宽范围**：

```
30 V → Mmin（约 40 V）  只需要 1.33 倍增益
对称发波能提供 0.55 → 1.00  共 1.8 倍
```

**1.8 倍的旋钮，去覆盖 1.33 倍的需求，余量充足。** 而在这么窄的带里，对称发波的"刻度糊"根本不是问题——因为 `d` 从 0.05 走到 0.2 就够用了，后面 0.2 到 0.45 走的是空行程，白走但无害。

同时它还白拿了两个好处：`Cr` 全程在 `Vin/2`（没有充电瞬态），两管导通时间相等（损耗均衡）。

**如果你需要从 0 爬到 `Mmin`（比如你的 0 ~ 12 V），这个方案就不成立了**，因为对称发波的下限是 0.55，够不到 0。那时候必须换互补发波，或者加一级 `ConVolt`。

### 9.6 三个值得抄的细节

**（1）积分器抗饱和的写法**

钳位时直接把 `integral` 置成 `clamp值 × Ki`，让 PI 输出正好等于钳位值。这样退出钳位时不会有积分回绕，比只写 `if (out > max) out = max` 干净得多。而且上下两个方向都钳了——60 kHz 就是防容性区的最后一道闸。

**（2）输出过压用"电压抬升速率"检测**

带载时记下 `vtemp`，如果 `Vout` 突然比之前高 3 V，直接判过压关机。这比固定 OVP 阈值快得多，专门抓"环路失控、输出飞掉"这种工况——正好对应容性区失控和硬开关 `dv/dt` 干扰。

**（3）同步整流的开关都带电流门限和延时**

`iOut > 4 A` 连续 1000 拍才开 SR，`iOut < 2 A` 立刻关。软启动和轻载阶段不开 SR，避免 SR 误导通。

### 9.7 四处不能照抄

| 位置 | 它的做法 | 为什么你不能抄 |
|---|---|---|
| `Transition` 入口 | 从 80 k / d≈0.3 硬跳到 250 k / d=0.05 | 这是充电机，**电池把输出钳住了**，`Vout` 掉不下去。电压源带容性负载这么跳会明显跌落 |
| `ConVolt` | 120 kHz 定频 + 占空比调压保持 30 V | 本质是把 LLC 当 buck 用，效率低。只适合短时待机，不适合长时间 |
| PFM 段 SR | `DriverPwm.SynDrv = 0`，SR 代码全注释 | 这一版**放弃了同步整流**，别以为那是标配 |
| `d` 起点 | 5% | 因为它 250 kHz 下 5% 正好等于死区。你的频率不同，这个数要重算 |

## 第 10 章 两种软启动策略的完整对比

### 10.1 定义

**方案一：PWM + PFM 混合软启动**

固定频率（取 `fmax`），占空比从下限爬到最大（对称或互补发波），然后占空比固定 0.5，开始调频。

**方案二：纯 PFM 扫频软启动**

从远高于 `fmax` 的初始频率起扫，全程 50/50 互补（扣除固定死区），在几十毫秒内平滑降到目标频率。

### 10.2 对比矩阵

| 维度 | 方案一（混合） | 方案二（纯扫频） | 说明 |
|---|---|---|---|
| 稳态直流偏磁 | **无** | **无** | `Cr` 隔直，两者都自动平衡 |
| 瞬态伏秒不平衡 | 有（`Cr` 充电） | 有（起扫瞬间 `Cr` 从 0 建立） | 两者都有，量级都不大 |
| 磁通摆幅 | **更小**（∝ d） | 最大（满伏秒） | 反直觉，但这是事实 |
| ZVS | **丢**（空档期硬开通） | **保** | 方案一的主要代价 |
| 硬开关损耗 | 16 W 量级（10 ms → 0.16 J） | ≈ 0 | 热上不致命，EMI 上致命 |
| 电流应力对称性 | 差（互补 37.6% 不对称；对称则均衡） | 好 | 影响温升分布 |
| 增益刻度 | 对称糊 / 互补干净 | 干净 | **第二版新增，选型关键** |
| 冲击电流抑制 | 好（脉宽限能量） | 极好（高频高阻抗） | 两者都够用 |
| 控制复杂度 | 高（两套发波 + 交接） | 低（只改周期寄存器） | — |
| 适用输出范围 | **宽**（可低于 `Mmin`） | 窄（必须高于 `Mmin`） | **这才是选型的决定因素** |

### 10.3 四条需要修正的流行说法

**（1）"小占空比必然直流偏磁、导致饱和"——错**

`Cr` 是隔直电容，稳态伏秒自动平衡。磁通摆幅 ∝ d，小占空比离饱和更远。真正的风险是"脉宽 < 死区/驱动延迟"导致两个半周实际导通时间不等。

**（2）"硬开关损耗巨大"——对，但量级要算清**

`2 × ½·Coss·Vin²·fs`，0.5 nF / 400 V / 200 kHz 下约 16 W。持续 10 ms 只有 0.16 J，热上无感。**真正的伤害是 `dv/dt` 引起的采样干扰和误保护。**

**（3）"高频起扫 ZVS 极易实现"——方向反了**

励磁电流峰值 `Im = Vin/(4·Lm·fs)`，**与频率成反比**。ZVS 判据：

```
½·Lm·Im² ≥ Coss·Vin²
```

代入得最高可 ZVS 频率：

```
fs_ZVS_max = 1 / sqrt(32·Lm·Coss)
```

以 `Lm = 200 μH`、`Coss = 0.5 nF` 计，`fs_ZVS_max ≈ 559 kHz`；若 `Coss = 1.5 nF`，只有 **323 kHz**。

**所以"抬 fmax 来扩增益范围"这条路，是用起扫段的 ZVS 余量换的。** `fmax` 翻倍，可用能量掉到 1/4。

**（4）"工业界无一例外用扫频"——不成立**

L6599、UCC25600、C2000 参考设计确实都是扫频，那是因为它们的输出范围窄。宽范围产品用混合的一大把——本文分析的那台 1600 W 充电机就是。

### 10.4 选型判据

```
Vout_min > Mmin·Vin/(2n)  →  方案二，别碰占空比
Vout_min < Mmin·Vin/(2n)  →  方案一，且 A 段用互补发波（范围宽）
只需要 1.3 倍左右增益带   →  方案一，A 段可用对称发波（无 Cr 瞬态）
```

## 第 11 章 设计规则与验证

### 11.1 决策树

```
开始
 │
 ├─ 先测 M–d 曲线（f=fmax，互补，d: 0→0.5）
 │
 ├─ Vout_min > Mmin·Vin/(2n) ？
 │    ├─ 是 → 纯 PFM 扫频
 │    │        fstart = 1.2~1.5 × fmax
 │    │        50/50 互补，d 全程不变
 │    │        fmin 硬钳位在 fpeak 之上 10%
 │    │
 │    └─ 否 → 必须混合
 │              A 段：f = fmax，d: 0.05 → d_max（互补）
 │              A 段结束时 Vout 落在 Mmin 附近
 │              B 段：d = 0.5，f: fmax → f_op
 │
 └─ 只需要一个低压待机点？
      └─ 单独做 ConVolt 或 burst，不要混进软启动路径
```

### 11.2 五个关键公式（全部换成正确的）

**（1）互补发波的增益**

```
M(d) / M(0.5) = sin(π·d)
```

用途：估算交接台阶。`d = 0.45` 时 1.2%，`d = 0.3` 时 16%，`d = 0.07` 时 3.4 倍。

**（2）对称发波不是增益旋钮**

```
理想三电平：|V(f)| = 0，|V(2f)| = (2/π)·sin(2πd)·Vin
真实电路：  增益下限由 t_slew 决定，不由 d 决定
t_slew = 2·Coss·Vin / |i_Lr|
```

用途：**判断能不能用对称发波做软启动。** 如果 `t_slew` 和空档 `(0.5−d)T` 同量级，就别用它当旋钮。

**（3）`Cr` 的直流工作点**

```
互补：Vcr = d · Vin
对称：Vcr = Vin / 2   （与 d 无关）
```

用途：核算电容电压应力；判断 `d` 跳变时的充电电流。**对称发波没有充电瞬态，互补有。**

**（4）磁通摆幅**

```
ΔB = (Vin/2) · d · T / (N · Ae)
```

用途：确认小占空比下磁通更安全，而不是更危险。

**（5）ZVS 频率上限**

```
fs_ZVS_max = 1 / sqrt(32 · Lm · Coss)
```

用途：判断 `fmax` 能不能再往上抬。

### 11.3 验证清单

| 项 | 怎么测 | 合格判据 |
|---|---|---|
| M–d 曲线 | `f = fmax` 固定，互补，`d` 从 0 扫到 0.5，记录 `Vout` | 单调；能覆盖你的输出下限 |
| 频率指令 | 抓 DAC 或调试变量 | 全程不低于 `fpeak` 钳位；交接后不贴 `fmax` |
| 原边电流对称性 | 带复位的电流互感器或罗氏线圈 | 正负对称，基线不漂 |
| `Cr` 电压 | 高压差分探头 | 互补在 `d·Vin`，对称在 `Vin/2` |
| 中点波形 | 差分探头看 `v_ab` | 确认是方波/梯形/三角，和你的假设一致 |
| ZVS | 看 `Vds` 关断波形 | 无密勒平台后的振荡，无硬开关尖峰 |
| 两管温升 | 分别测壳温 | 差值 < 5 ℃ |
| 交接点 | 同时抓 `Vout` 与频率 | 过冲 < 5%，频率不触顶 |
| 重复性 | 同一工况启动 10 次 | 峰值电压离散度 < 3%（离散大 = 增益随负载漂移） |

**最后一项是第二版新加的。** 对称发波做软启动时，"同一工况启动 10 次，每次波形都不一样"是最典型、也最容易被忽略的故障特征。它的根因是增益不是 `d` 的函数，而是电流的函数。

### 11.4 五个常见错误

1. **把中点当成理想开关** —— 空档期它浮空，波形由电流积分决定，不由栅极决定
2. **用对称发波当增益旋钮** —— 刻度糊、下限由 `Coss` 定、增益随负载漂移
3. **用占空比去够目标电压** —— 交接时频率无路可走，必然振荡
4. **认为低压侧是容性区** —— 容性区在低频侧，低压侧反而最安全
5. **把 `fmax` 当无限可调** —— ZVS 余量按 `1/f²` 衰减，抬高一倍掉到四分之一

## 附录 C 模型局限与复现方法

### C.1 三个必须写进留底的局限

1. **`Coss` 决定低端增益。** 对称发波 `d = 0.05` 的稳态电压在 1.7 ~ 4.0 V 之间随 `Coss` 变化，这一条必须实测标定，不能引用本文数字。
2. **无损耗、无漏感。** 看不到二极管压降、绕组损耗、漏感引起的占空比丢失。
3. **变压器理想。** 只能看磁通"走不走偏"，看不到"什么时候饱和"。

### C.2 两个建模陷阱

**（1）整流器不能用 `vp = n·Vo·sign(ip)`**

这个模型允许变压器出现直流电压，违反伏秒平衡。实测：`Cr` 会稳在 175 V 而不是 200 V，差 12.5%。必须用"导通/断开状态机 + 电压钳位"。

**（2）步长不够细会把脉宽量化**

`d = 0.05` 时脉宽只有 250 ns，每周期采 160 点相当于占空比本身有 12% 误差。同一组参数能算出 1.24 V 也能算出 3.50 V。

| 每周期点数 | 等效脉宽分辨率 | `d = 0.05` 稳态 Vout |
|---|---|---|
| T/120 | 0.83% | 3.37 V |
| T/320 | 0.31% | 3.50 V |
| T/640 | 0.16% | 3.56 V |

**结论：小占空比工况下步长必须细到 `T/300` 以上，否则你测到的"低占空比增益"是数值噪声。**

### C.3 怎么复现

模型脚本为 `llc_verify.py`，参数在文件开头的 `P` 字典里。把 `Lr / Cr / Lm / n / Coss / fmax` 换成你自己的实测值，跑一次约 40 秒，会生成报告和 7 张波形图。

**换完参数后，先看两件事：**

1. 用例 0 的自检表——`fn = 1` 处偏差应该在 1% 以内，否则参数或模型有问题；
2. 用例 2 的 M–d 表——如果 `d = 0.05` 的增益和你实测差很多，说明你的 `Coss` 不是 1.5 nF，先用实测值反推。

## 结语

回到最初那个问题："我要对称发波，是因为不对称发波会导致磁不平衡、发烫，我讲得对不对？"

**直觉对了一半，但对的那一半不在你以为的地方。**

半桥 LLC 里不存在"稳态直流偏磁"这个问题——`Cr` 就是为此存在的。真正存在的是三个东西：**窄脉冲导致的实际伏秒不等**、**空档期丢失的 ZVS**、**占空比带来的增益粗调台阶**。

而第二版要补一句更根本的：**对称发波连"增益粗调"这个功能都做不好。** 因为中点浮空，它的增益是电流的函数，不是占空比的函数。你把它当旋钮拧，实际拧的是一个刻度会随负载变化的旋钮。

所以正确的动作不是"想办法平滑地切换"，而是：

1. **先测 M–d 曲线**，用互补发波测，别用对称；
2. **要宽范围就用互补发波**，它的 `sin(πd)` 是干净的；
3. **要无 `Cr` 瞬态就用对称发波**，但只在窄增益带里用；
4. **交接点定在占空比最大处**，让 `Mmin` 对应的电压自己出现在那里；
5. **给频率留余量**，否则无论怎么平滑交接，环路都会顶在 `fmax` 上打转。

一句话：**软启动的难点不在"怎么切"，在"有没有可切的点"。**
