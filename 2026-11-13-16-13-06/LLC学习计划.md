# 半桥 LLC 学习计划

> 条件：10 年嵌入式软件经验，非科班；有量产代码、原理图、开环仿真模型；无计算书。
> 仪器：示波器 + 高压差分探头。缺 LCR 表、缺电子负载、缺可调直流源。
> 投入：每周 5 小时。目标：能独立做 LLC 设计。

---

## 一、先把预期摆正

| 目标 | 现实周期（5h/周） | 说明 |
|---|---|---|
| 看懂、能改、能调、能定位炸机 | 约 4 个月 | 走到阶段 E 即可 |
| **能独立做设计（你的目标）** | **约 8–9 个月** | 需要走完全部六个阶段 |
| 能独立绕变压器、定磁芯 | 不在这份计划内 | 必须有人带，见第六节 |

每周 5 小时意味着：**不要试图并行学两件事**。这周只碰一个主题，哪怕只搞懂一个小问题。

---

## 二、三个关键判断（先说结论）

### 1. 最该花钱的不是开发板，是一支手持 LCR 表

你缺的是计算书。计算书拿不到，唯一的路是**反推**，反推第一步必须测出 Lr、Lm、Cr、匝比。

- 需要：100kHz 测试频率、能测 μH 级电感（手持电桥，五百元档就够，如 UT612 一类）
- 为什么不是开发板：开发板解决"我没东西练手"，但你现在卡的是"我算不出这台机器为什么这么设计"。板子解决不了这个。

### 2. 你手上的资料，价值排序是：开环仿真模型 > 量产代码 > 原理图

- **开环仿真模型是最好的老师**，因为参数可以随便改。这是你唯一的"实验台"。
- **量产代码**：信息量很大，但 90% 是通讯、上报、故障记录。见阶段 E，只看三处。
- **原理图**：只是地图，不是知识。

### 3. 拿不到计算书是优势，不是劣势

读一遍别人的计算书，你只会"哦，是这样"。反推一遍，你会知道每个数字为什么是这个值、改一个会牵动什么。这个差别就是"会用"和"会设计"的差别。

## 三、六个阶段

### 阶段 A｜建立坐标系（第 1–2 周，10h）

| 周 | 做什么 | 交付物 |
|---|---|---|
| 1 | 从原理图和铭牌上抄下所有硬指标：Vin 范围、Vo、Po、开关管型号、谐振电容值、变压器匝比、死区时间、整流方式 | 一页 A4《这台 LLC 的规格卡》 |
| 2 | 在原理图上把 Lr、Lm、Cr、死区、驱动、采样点全部圈出来标数值。搞清楚 LLC 在整机里的位置（前级 PFC 之后？后级 DC/DC？） | 一张标注过的原理图截图 |

**验收**：能不看资料，口述这台 LLC 的输入、输出、功率和它上游是什么。

---

### 阶段 B｜物理直觉（第 3–6 周，20h）

每周只干一件事：**画一个开关状态**。

半桥 LLC 一个完整周期有 4 个状态。每周画一个，画出：哪些管子导通、谐振电流往哪流、Lm 参与不参与谐振、副边哪个二极管导通。

| 周 | 主题 | 配套动作 |
|---|---|---|
| 3 | 状态 1：上管导通，Lr+Cr 谐振，Lm 被副边钳位 | 画完去开环仿真里对着波形找这一段的电流形状 |
| 4 | 状态 2：上管关断，死区，谐振电流给下管结电容放电 | 重点看死区那几十纳秒里电流怎么走 |
| 5 | 状态 3：下管导通，反向谐振 | 注意电流方向翻转 |
| 6 | 状态 4：下管关断，死区，回到状态 1 | 此时 Lm 参与谐振，频率变成 fr2 |

**验收**：能在纸上完整画出 4 个状态和电流路径，并说清"为什么开关管是在零电压下开通的"。

这一步别偷懒。**这是你唯一一次机会，把"电路"变成脑子里的动画**。后面所有公式都建立在这个动画上。

---

### 阶段 C｜增益曲线 + 反推计算书（第 7–16 周，50h）★ 核心

这 10 周占整个计划三分之一，是整个计划的重心。

| 周 | 做什么 | 产出 |
|---|---|---|
| 7 | 学 FHA 的两个假设：方波只取基波、整流侧折算成电阻。**不用背公式**，要能说清"为什么可以这么近似" | 一页笔记 |
| 8 | 看懂增益公式的物理含义：为什么 fn=1 时增益恒等于 1，为什么 fn 增大增益下降 | 手推一遍 |
| 9 | **手算 5 个点**：fn = 0.6 / 0.8 / 0.9 / 1.0 / 1.2，用计算器，画在方格纸上 | 手绘曲线 |
| 10 | 打开 `llc-gain-curve.html`，把你手算的 5 个点对上去。然后单独改 k、单独改 Q，各看一次曲线怎么动 | 理解"只有 k 和 Q 两个自由度" |
| 11 | **测参数**（见第四节）：LCR 表测 Lr、Lm、Cr，测匝比 n | 四个实测数字 |
| 12 | 把实测值填进计算器，读出理论 fsw 范围 | 理论值 |
| 13 | **去代码里找实际 fsw 范围，对比。** 这是整个计划的关键时刻 | 一张对比表 |
| 14 | 解释偏差：死区、寄生参数、整流管压降、FHA 近似误差、采样误差 | 偏差归因清单 |
| 15–16 | 写出你自己的计算书，格式照 AN-4151：规格 → 匝比 → k/Q → Lr/Cr → fsw 范围 → 器件应力 | **3–5 页《LLC 主参数计算书》** |

**验收**：你的计算书算出来的 fsw 范围，和量产代码里的实际范围误差在 15% 以内。做到了，你就真的懂这台机器了。

> 如果第 13 周对不上，别急着往下走。对不上就是最好的学习材料——去找硬件同事问一句"这个频率范围是怎么定的"，往往十分钟胜过看一周书。

---

### 阶段 D｜仿真对齐（第 17–20 周，20h）

把开环模型当成实验台。

| 周 | 做什么 |
|---|---|
| 17 | 跑通模型，固定占空比 50%，扫 fsw，记录每个频率下的输出增益 |
| 18 | 把扫出来的点画成曲线，和阶段 C 的手算曲线叠在一张图上 |
| 19 | 单变量实验：Lr ±20%、Lm ±20%、Cr ±10%，各跑一次，记录 fsw 范围怎么变 |
| 20 | 加死区、加寄生（绕组电阻、二极管压降），看波形和增益怎么偏 |

**验收**：仿真曲线与手算误差 < 10%，并且能说出偏差来自哪几项。

**这一阶段的意义**：以后你拿到任何一台陌生 LLC，先跑仿真，再上电。这个习惯能救你的器件。

---

### 阶段 E｜代码解剖（第 21–26 周，30h）

**只读三处，别通读。**

| 周 | 主题 | 看什么 |
|---|---|---|
| 21 | 状态机 | 启机 → 软启动 → 正常运行 → 保护 → 故障恢复，每个状态怎么进、怎么出、超时多少 |
| 22 | PFM 频率生成 | fsw 从哪个变量来？周期寄存器值怎么算？有没有最小/最大频率钳位？ |
| 23 | 软启动 | 起始频率多高、降频斜率多少、多久到目标。为什么必须从高频起 |
| 24 | 保护 | OCP / OVP / 短路 / 防容性负载 / 过温，各自的阈值、延时、动作 |
| 25 | 环路 | 电压环、电流环（如果有）的采样点、滤波、PID 参数。**只看，不改** |
| 26 | 加观测 | 在不改逻辑的前提下，把实时 fsw、M、占空比打到调试口或串口，跑起来看 |

**验收**：画出一页《LLC 控制代码地图》，能指着图讲清"输出电压低了，代码是怎么一步步把频率调下来的"。

> 第 26 周的"加观测"很重要。你十多年嵌入式经验在这里是绝对优势——别人得靠猜，你可以直接把内部变量打出来。

---

### 阶段 F｜上电实测 + 磁件入门（第 27–34 周，40h）

#### 安全，先看这段

- 母线几百伏，LLC 一次侧**全是浮地高压**
- 必须用**隔离变压器**给整机供电
- 测一次侧只能用**高压差分探头**，绝不能用普通探头的接地夹
- 谐振电流用电流探头或罗氏线圈；没有的话，退而求其次测谐振电容两端电压，相位关系同样能判断 ZVS
- 每次断电后等母线电容放电，用万用表确认电压归零再动手
- **单人操作，不赶时间**

#### 四周实测

| 周 | 测什么 | 看什么 |
|---|---|---|
| 27 | 空载/轻载启动 | 软启动过程、起始频率、有没有容性区冲击 |
| 28 | 满载稳态 Vds | 是不是真的 ZVS？开通前 Vds 有没有降到 0？死区里振铃多大？ |
| 29 | 谐振电流波形 | 是不是正弦？有没有畸变？畸变说明什么？ |
| 30 | 扫负载、扫母线 | 记录每个工况的 fsw，和你阶段 C 的表格对照 |

#### 磁件：只学"够用"的部分

自学能学会的：匝比、磁芯选型（面积积 AP 法）、气隙与电感量的关系、趋肤效应与股数、铜损铁损的粗算。

**必须有人带的**：绕法（三明治绕法为什么能降漏感）、层间电容、温升实测、绝缘与爬电距离。这几项在书里学不会，找公司做变压器的同事，请人吃饭都比自己啃快。

## 四、反推计算书：具体操作

这是整份计划里最值钱的一段。

### 第 1 步：测 Lr 和 Lm

LCR 表，100kHz 档：

1. **副边开路**，测原边电感 → 得到 `Lr + Lm`
2. **副边短路**，测原边电感 → 得到 `Lr`（Lm 被副边反射短路掉了）
3. `Lm = 步骤1 - 步骤2`

> 注意：副边短路测到的其实是 Lr 加上漏感，对工程估算够用。如果你要更准，得用阻抗分析仪做扫频。

### 第 2 步：测 Cr

直接读谐振电容丝印。多个并联就按并联算。拆下来单独测更准。

### 第 3 步：测匝比 n

给副边加**低压交流**（5V / 1kHz 信号源，或变压器降压后的低压），用示波器同时测原边和副边电压，比值就是 n = Np/Ns。

**别用万用表直流档量**——变压器不通直流，你只会量到 0。

### 第 4 步：算四个派生量

```
fr1 = 1 / (2π√(Lr·Cr))        ← 主谐振频率
fr2 = 1 / (2π√((Lr+Lm)·Cr))   ← Lm 参与时的谐振频率
k   = Lm / Lr                 ← 决定增益范围
Q   = √(Lr/Cr) / Rac          ← 满载时最大，Rac = 8n²Vo²/(π²Po)
```

### 第 5 步：算所需增益范围

```
M = 2n·Vo / Vin     （半桥 + 全桥整流）
```

两个角点决定频率范围：
- `Vin_min + 满载` → M 最大 → **fsw 最低**
- `Vin_max + 轻载` → M 最小 → **fsw 最高**

### 第 6 步：在增益曲线上读 fn，换算成 fsw

用 `llc-gain-curve.html`，填进去，直接读表。

### 第 7 步：和代码对比

去代码里找 fsw 的最小值、最大值、软启动起始频率。对上了，收工；对不上，逐条归因。

## 五、资料（按重要性排序，不要贪多）

1. **ON/Fairchild AN-4151**《Half-bridge LLC Resonant Converter Design Using FSFR-series》
   最好的入门计算书范本，有完整算例。**照着做一遍**，这是阶段 C 的模板。
2. **ST AN2450**《LLC resonant half-bridge converter design guideline》
   另一套完整算例，用来交叉验证你的算法。
3. **Infineon 的 LLC 设计笔记**（搜 "Infineon LLC resonant converter operation and design"）
   FHA 推导讲得最清楚，配图最好。
4. **《精通开关电源设计》Maniktala**
   补基础：RLC 谐振、磁性元件、损耗。不用全读，当字典。
5. 先别碰 Pressman 那本《开关电源设计》，太厚，会劝退。

**看资料的纪律**：同一个问题，最多看两份资料。第三份开始就是重复和拖延。

## 六、不要做的事

| 不要 | 原因 |
|---|---|
| 通读量产代码 | 90% 与 LLC 原理无关，会耗尽你的 5 小时/周 |
| 一上来学磁件设计 | 会陷进去，且没有实践就无法验证。放到阶段 F |
| 先买大功率 LLC 开发板 | 贵、危险、资料未必全。优先借公司样机 |
| 没有差分探头就测一次侧 | 会烧探头、烧板子、伤人 |
| 同时学 PFC + LLC | 5 小时/周只能专注一件事 |
| 纠结 FHA 不够准 | 工程上就是这么算的。要更准，靠仿真和实测修正 |

## 七、什么时候该买硬件

| 时机 | 买什么 | 预算 |
|---|---|---|
| **现在** | 手持 LCR 表（100kHz） | 约 500 元 |
| 现在 | 电流互感器或罗氏线圈（测谐振电流） | 100–300 元 |
| 阶段 D 之后 | 如果借不到样机，再考虑小功率 LLC EVM | 看型号 |
| 阶段 F | 大功率电阻箱 / 水阻（做负载） | 几百元 |

**如果要买开发板**，唯一的标准是：**附带 Excel 计算表和完整设计文档**。没有计算表的板子，对你现在这个阶段价值不大。TI 的 UCC25640x 系列、ST 和 onsemi 的 LLC 评估板都带设计包，可以看。

但更划算的顺序是：先借公司一台旧样机 + 买 LCR 表，等阶段 D 走完再决定要不要买板。

## 八、每周怎么执行

每周 5 小时，建议这样切：

- **3 小时**：主任务（当周表格里那一件事）
- **1 小时**：动手（画图 / 手算 / 跑仿真 / 测数据）
- **1 小时**：写笔记 —— 只写"我这周搞懂了什么"和"还有什么没懂"

每周结束时问自己一句：**这周我能不能用一个具体的东西证明我学会了？**（一张图、一段波形、一个数字、一段能讲出口的解释）

答不上来，就说明这周白过了，下周重来，不要往下推。

---

## 九、一句话总结

> 你的优势是十多年软件工程训练出来的**系统性思维和调试能力**——LLC 的难点从来不在代码，而在"看不见的电流怎么流"。
>
> 所以顺序是：先把电路变成脑子里的动画（阶段 B），再把动画变成一条曲线（阶段 C），最后才去碰代码（阶段 E）。
>
> 反过来做，就是大多数软件工程师学 LLC 失败的原因。
