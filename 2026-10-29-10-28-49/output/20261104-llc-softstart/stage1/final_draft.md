# 半桥 LLC 软启动：从增益曲线到工程实现

> 本文以一台 1600 W 充电机的实际控制代码为样本，把 LLC 软启动的每一个决策都拆到"为什么必须这样"的层面。全文回答五个问题：为什么要软启动、对称发波与互补发波是什么关系、30% 跳 50% 为什么必然振荡、低压段到底该用什么旋钮、企业级工程为什么最终选了混合方案。

## 导读

软启动的本质不是"慢慢加大能量"，而是**在增益最低的工作点上起机，然后让增益单调、平滑、无台阶地爬到目标值**。半桥 LLC 有两个旋钮——频率和占空比，但占空比不是"第二个独立调节量"，它是增益的粗调，代价是丢 ZVS、增 EMI、产生电流不对称。绝大多数振荡和过冲，根因都不是"切换太突然"，而是**频率没有余量，被迫用占空比去补量程**。

## 阅读前提

- 目标读者：做数字控制 LLC 的电源工程师，能看懂 C 代码和基本控制框图
- 前置知识：半桥拓扑、谐振腔（Lr / Cr / Lm）、PI 调节器、STM32 高分辨率定时器
- 本文约定：`d` 表示单个开关管的导通占空比（0 ~ 0.5），`D` 表示同一符号；`fmax` 表示最高开关频率，`fmin` 表示最低开关频率；`M` 表示归一化直流增益

## 第 1 章 软启动到底在解决什么问题

### 1.1 如果直接给 50% 满占空比

把 LLC 从"停振"直接推到"50% 互补、工作频率"，会同时发生三件事：

1. **输出电容充电电流失控。** 输出从 0 V 起充，误差放大器饱和，环路要求最大增益，频率一路压到下限。此时原边电流只受谐振腔阻抗限制，峰值可达额定的数倍。
2. **第一次开关就是硬开关。** 起机瞬间谐振腔里没有电流，MOS 的结电容是满电荷状态，第一个脉冲打上去就是 400 V 硬开通，`Coss` 储能全部变成热和 EMI。
3. **Cr 的初始电压是 0，不是 Vin/2。** 稳态时隔直电容 Cr 上的电压由占空比决定（后面会证明它等于 `d·Vin`），但上电瞬间它是 0。前几十个周期里，加在变压器上的正负伏秒严重不平衡，磁通会往一个方向走。

第三点是最容易被忽略、也最容易烧管的。

### 1.2 软启动的三个目标

| 目标 | 物理量 | 判据 |
|---|---|---|
| 电流可控 | 原边谐振电流峰值、输出充电电流 | 不超过额定 1.2 ~ 1.5 倍 |
| 磁通可控 | 每半周伏秒积 | 正负对称，无直流偏置累积 |
| 损耗可控 | 开关损耗、`dv/dt` | 尽量全程 ZVS，边沿不产生采样干扰 |

### 1.3 一个必须先建立的认知

LLC 有两个可调量：开关频率 `f` 和占空比 `d`。很多人下意识把它们当成"两个平级的旋钮"，可以互相替补。**这个直觉是错的。**

- 频率是**连续、无损、保 ZVS** 的旋钮，但它的调节范围有硬边界（`Mmin` 到 `Mmax`）。
- 占空比是**粗调、有损、丢 ZVS** 的旋钮，它的唯一价值是**突破 `Mmin` 下限**。

所以软启动的正确表述是：**在增益最低的状态下起机，然后让增益单调地爬到工作点。** 用哪个旋钮，取决于你的输出电压范围是否超出了频率能覆盖的区间。这一点会在第 9 章展开。

## 第 2 章 先画地图：LLC 的增益曲线

### 2.1 基波近似（FHA）增益公式

忽略谐波，只取开关频率处的基波分量，半桥 LLC 的归一化增益为：

```
M(fs) = 1 / sqrt( [1 + Ln·(1 - (fr/fs)²)]² + [Q·(fs/fr - fr/fs)]² )
```

其中：

```
Ln = Lm / Lr                        （电感比，典型 3 ~ 10）
Zr = sqrt(Lr / Cr)                  （特征阻抗）
Q  = Zr / Rac                       （品质因数，Rac = 8n²Vout²/(π²Pout)）
fr = 1 / (2π·sqrt(Lr·Cr))           （谐振频率）
```

三条必须记住的性质：

1. **`fs = fr` 时 `M = 1`。** 这是增益曲线的"锚点"。
2. **`fs` 升高，`M` 单调下降。** 这就是 PFM 调压的全部依据。
3. **`Q` 越大（负载越重），峰值增益越低。** 所以最恶劣工况是"满载 + 最低输入电压"。

### 2.2 容性区到底在哪一侧

这是最常被搞反的一件事。

增益曲线有一个峰值点 `fpeak`。`fpeak` **左侧**（频率更低、增益更高）是**容性区**：谐振腔输入阻抗呈容性，电流**超前**电压。`fpeak` **右侧**是**感性区**：电流**滞后**电压，滞后的电流在死区里帮管子抽干结电容，才有 ZVS。

由此推出两条反直觉但正确的结论：

- **输出电压越低，需要的增益越低，工作频率越高，工作点越往右，越深入感性区。** 所以低压侧是整条曲线上最安全的一段。
- **容性区只会在"环路把频率压到 `fpeak` 以下"时进入**，也就是"增益需求超过了当前 Q 下的峰值增益"。触发条件是电流太大（输出短路、输出电容太大、启动充电太猛），不是电压太低。

### 2.3 Mmin：LLC 的量程下限

频率不可能无限升高。受死区占比、驱动损耗、ZVS 余量三重限制，工程上一定有一个 `fmax`。`fmax` 处的增益就是 `Mmin`，它对应的输出电压就是**这台 LLC 用调频能产生的最低电压**。

```
Vout_min(PFM) = Mmin · Vin / n
```

低于这个电压，**频率调到无穷大也降不下去**。这不是稳定性问题，是**量程问题**——就像用只能读到 0 的秤去称负数。

想把 `Mmin` 压低，只有三条路，每条都有代价：

| 手段 | 效果 | 代价 |
|---|---|---|
| 提高 `fmax` | `Mmin` 下降 | 死区占比变大、驱动损耗上升、ZVS 余量按 `1/f²` 衰减 |
| 增大 `Ln`（加大 `Lm`） | 曲线整体下移、范围变宽 | 励磁电流减小是好事，但峰值增益和带宽变化，需重算 |
| 增加第二个旋钮（占空比 / burst） | 突破 `Mmin` 限制 | 丢 ZVS、增 EMI |

### 2.4 三个必须记住的频率

```
fpeak   —— 增益峰值点，容性区与感性区的分界，绝不能越过
fmax    —— 最高工作频率，决定 Mmin
fmin    —— 最低工作频率，决定 Mmax，通常取 1.2 ~ 1.5 倍 fpeak 以上留余量
```

工程上必须做的一件事：**给 `fmin` 设硬钳位，位置在"最恶劣 Q 下的 `fpeak`"之上，留 10% 余量。** 这一条比任何发波技巧都更能防容性区。

## 第 3 章 发波：对称与互补不是两种模式

### 3.1 半桥只有两个状态

半桥上管 Q1、下管 Q2，中点电压只有两种：Q1 通时为 `Vin`，Q2 通时为 `0`。所以"发波"这件事，本质就是**决定中点电压在一个周期里怎么分配**。

### 3.2 占空比 d 的两种画法

**画法一：互补发波（d = 50%）**

Q1 导通半个周期，Q2 导通另外半个周期，中间插死区。中点电压是一个干净的 ±`Vin/2` 方波。

**画法二：对称发波（d < 50%）**

把两个脉冲都"压窄"，各自居中在 `T/4` 和 `3T/4`，宽度都是 `d·T`，中间留出 `(1-2d)·T` 的空档。上管和下管的导通时间**完全相等**。

### 3.3 关键结论：50% 的对称发波就是互补发波

当 `d = 0.5` 时，两个脉冲宽度都是 `T/2`，首尾相接，中间的空档消失——两条路合成一条。

```
d = 0.05  →  两个 5% 脉冲 + 90% 空档
d = 0.25  →  两个 25% 脉冲 + 50% 空档
d = 0.45  →  两个 45% 脉冲 + 10% 空档
d = 0.50  →  两个 50% 脉冲 + 0% 空档  ≡ 互补发波
```

**所以不存在"从对称模式切换到互补模式"这件事。** `d` 就是从 0 到 0.5 的一个连续旋钮，0.5 只是它的终点。把它当成两种需要"切换"的模式，正是振荡的来源。

### 3.4 代码里怎么算

企业工程里 `SHRTIMERdrive()` 的分支逻辑，把这件事写得很清楚：

```c
/* 周期寄存器：680MHz 定时器时钟 / 目标频率 */
pre  = 680000000.0f / DriverPwm.Plv;

if (CtrMode != OvLoadPFM) {
    /* ---- 对称发波：脉冲居中于 T/4 与 3T/4 ---- */
    temp  = pre >> 2;                    /* T/4 */
    bemp  = pre - temp;                  /* 3T/4 */
    time1 = ((float)half) * DriverPwm.Duty;
    duty  = (uint16_t)time1;             /* 半宽 = T·d/2 */

    CMP1 = temp - duty;                  /* 脉冲 1 前沿 */
    CMP2 = temp + duty;                  /* 脉冲 1 后沿 */
    CMP3 = bemp - duty;                  /* 脉冲 2 前沿 */
    CMP4 = bemp + duty;                  /* 脉冲 2 后沿 */
} else {
    /* ---- 互补发波：50/50 + 固定死区 ---- */
    CMP1 = LLC_DEADTIME;
    CMP2 = half - LLC_DEADTIME;
    CMP3 = half + LLC_DEADTIME;
    CMP4 = pre  - LLC_DEADTIME;
}
```

注意 `duty` 是**半宽**，所以脉冲总宽度是 `T·d`，两个脉冲加起来正好是 `2d·T`，空档 `(1-2d)·T`。

### 3.5 为什么工程停在 0.45 而不是 0.5

如果 `d = 0.5`，脉冲 1 的右沿（`T/4 + T/4 = T/2`）和脉冲 2 的左沿（`3T/4 - T/4 = T/2`）重合，死区变成 0，上下管直通。

留 5% 的空档，正好当死区用：250 kHz 下 5% = 200 ns，和代码里 `LLC_DEADTIME = 120` 计数（680 MHz 下约 176 ns）基本对齐。

**所以 0.45 不是随手写的，它是"对称发波能安全输出的最大占空比"。**

## 第 4 章 30% 跳 50% 为什么必然振荡

### 4.1 现象

在 30% 占空比时输出已经到目标电压，切到 50% 立刻振荡。这个观察是准确的，而且原因不止一个。

### 4.2 增益台阶到底多大：sin²(πd)

先纠正一个流传很广的错误：**基波幅值正比于 `sin²(πd)`，不是 `sin(πd)`。**

推导（对称三电平波形，取基波分量）：

```
b1 = (2/T)·[ ∫₀^{dT} sin(ωt)dt − ∫_{T/2}^{T/2+dT} sin(ωt)dt ]
   = (4/π)·sin²(πd)
```

归一化到 `d = 0.5`（此时 `b1 = 4/π`，即标准方波基波）：

| d | 0.05 | 0.10 | 0.20 | 0.30 | 0.40 | 0.45 | 0.50 |
|---|---|---|---|---|---|---|---|
| 相对基波 | 2.4% | 9.6% | 34.5% | 65.5% | 90.5% | 97.6% | 100% |
| 跳到 50% 的倍数 | 41× | 10.5× | 2.9× | **1.53×** | 1.11× | **1.02×** | 1× |

这张表是整篇文章最重要的一张。它说明三件事：

1. **曲线是 S 形的**：在 0.45 附近极平（2.4% 台阶），在 0.1 附近极陡（10 倍台阶）。
2. **30% → 50% 是 1.53 倍增益突变**，不是 1.24 倍。输出必然过冲。
3. **0.45 → 0.5 只有 2.5% 突变**，小到 PI 一个周期就能吃掉。这就是企业工程选 0.45 的定量依据。

### 4.3 第二个台阶：Cr 的直流工作点要跳

稳态时，中点电压的平均值必须等于 Cr 上的电压（否则初级电流会有直流分量）。中点电压在 `dT` 内是 `Vin`，其余时间是 `0`，所以：

```
Vcr = d · Vin
```

`d` 从 0.30 跳到 0.50，`Vcr` 就要从 `0.30·Vin` 充到 `0.50·Vin`。这段充电电流是额外叠加在谐振电流上的，输出会再冲一下，磁通也走一段。

### 4.4 根因：频率没有余量

上面两条只是"台阶"，台阶本身不一定导致持续振荡。真正让它变成极限环的是**频率已经顶到上限**：

```
现象：30% 占空比就到达目标电压
推理：50% 占空比 + fmax 下的增益已经超过目标
结论：要把增益压回去，频率必须高于 fmax —— 而 fmax 就是上限
```

于是环路看到过冲，把频率往上推，推到 250 kHz 顶死，进入积分限幅；输出掉下来，环路再往回拉。来回就是极限环。

**你实际上是在用占空比当"额外的降压旋钮"，去补频率上限不够的那部分增益。稳态能凑合，但一旦要把这个旋钮交还给频率，就必然出现台阶。**

### 4.5 "磁不平衡导致发烫"这个解释错在哪

这是最需要纠正的一条，因为它会引导你做出错误的设计取舍。

**半桥 LLC 的 Cr 本身就是隔直电容。** 它串在谐振腔里，稳态下初级电流的直流分量必须为零，所以变压器的伏秒**自动**平衡，跟你用什么占空比无关。`d = 30%` 互补驱动时，Cr 自己会稳到 `0.3·Vin`，把直流分量全吃掉。

而且磁通摆幅是**正比于 d** 的：

```
ΔB = (Vin/2)·d·T / (N·Ae)
```

`d` 越小，磁通摆幅越小，峰值磁通越低。**小占空比不但不会更容易饱和，反而离饱和更远。**

真正的代价是另外四样：

| 代价 | 机理 | 量级 |
|---|---|---|
| 增益下降 | 基波 ∝ sin²(πd) | 30% 时只剩 65.5% |
| 电流不对称 | 两个半周波形不同，峰值/有效值都变大 | 两管损耗不均，温差可达 10 ℃ 以上 |
| Cr 偏置 | `Vcr = d·Vin`，电容要按偏置后的电压重新核 | 30% 时多 0.3·Vin 直流应力 |
| 谐波与 EMI | 三电平波形的低次谐波大 | 传导干扰抬升 6 ~ 10 dB |

**"磁不平衡"真正会发生的地方是瞬态，不是稳态。** 具体是两个时刻：上电瞬间（Cr 从 0 开始）和 `d` 跳变瞬间（Cr 要从一个值充到另一个值）。这才是你该防的，而它跟"稳态用 30% 还是 50%"无关。

### 4.6 正确解法

**方案 A（推荐，业界标准）：纯扫频，占空比从头到尾 50/50。**

- 起始频率取 1.2 ~ 1.5 倍 `fmax`，50/50 互补，死区照常
- 频率按 S 曲线或指数从 `fstart` 扫到 `f_op`，10 ~ 50 ms
- 增益从 `Mmin` 平滑升到目标，全程 ZVS
- 配逐周期限流 + Vref 软启动（让环路追一个缓慢上升的基准）
- **前提是 `Mmin(fmax) < Mtarget`，并留 10 ~ 15% 余量**

**方案 B（输出范围宽、确实需要低于 `Mmin`）：两段式连续轨迹。**

- A 段：`d` 从 0 爬到 0.45，频率钉在 `fmax`，增益 0 → `Mmin`
- B 段：`d` 固定 0.5，频率从 `fmax` 扫到 `f_op`，增益 `Mmin` → 目标
- 交接点在 `(d = 0.45, f = fmax)`，是同一条轨迹上的一个点，**零台阶**

**方案 C（控制器改不了，只能做占空比软启动）：改爬坡形状。**

- 不要用线性，改用 `1−cos` 或 `sin` 形状。增益对 `d` 的斜率在 0.5 处趋近 0，末段天然平缓
- 同时让频率一起动，不要让"占空比涨的增益"和"频率降的增益"同时发生

## 第 5 章 7% 到 12V 再切 50%：为什么不保险

### 5.1 容性区在低频侧，不在低压侧

前面已经证明：输出电压越低 → 需要增益越低 → 频率越高 → 工作点越靠右 → **越深入感性区**。

所以 0 ~ 12 V 恰恰是整条曲线上**最安全**的一段。担心"低压启动容易进容性区"，是把容性区的位置记反了。

### 5.2 0 ~ 12 V 的真正问题是"够不着"

如果你的设计里 `fmax` 对应 12 V，那意味着 `Mmin` 对应 12 V。50% 占空比下，环路会顶在频率上限，输出停在 12 V 下不去——这是**量程不够**，不是稳定性问题。

用占空比降压，本质是在补量程，这个思路本身没错。错的是补的方式。

### 5.3 7% 是整条链上最糟的交接点

查 4.2 的表：`d = 0.07` 时相对基波只有 **4.8%**，跳到 50% 是 **21 倍**增益突变。

即使考虑空档期体二极管钳位会补掉一部分，实际台阶也远大于 30% → 50% 的 1.53 倍。所以这个方案不是"更保险"，是把台阶放大了一个数量级。

### 5.4 先做一件事：测出你自己的 M–d 曲线

在讨论"能不能这样切"之前，必须有一个数：

> 固定 `f = fmax`，让 `d` 从 0 扫到 0.5，记录 `Vout`。

判读方法：

- 如果 `d = 0.07` 给 11.8 V、`d = 0.5` 给 12 V → 说明占空比旋钮在 7% 就饱和了，这个方案没有意义
- 如果 `d = 0.07` 给 12 V、`d = 0.5` 给 55 V → 绝对不能这样交接

这个数不测出来，所有讨论都是猜。

### 5.5 让 12 V 自己出现在交接点上

既然 `Mmin(fmax)` 对应 12 V，那就别停在 7%：

1. `f` 固定在 `fmax`，`d` 从 0 爬到 0.45，`Vout` 从 0 升到约 12 V
2. `d = 0.45` 的那一刻，`Vout` 正好在设计点上，**这就是交接点，台阶只有 2.5%**
3. 然后 `d` 固定 0.5，`f` 从 `fmax` 扫到 `f_op`，`Vout` 从 12 V 升到 24 V

**占空比要爬到 0.45，不是停在 7%。** "升到 12 V 才开始调频"这个直觉是对的，因为 12 V 就是频率调不动的下限；错的是"怎么到 12 V"。

### 5.6 真正防容性区的三件套

跟占空比无关：

1. **最低频率硬钳位**：设在最恶劣 Q 下的 `fpeak` 之上，留 10% 余量
2. **逐周期限流**：限制原边或副边电流峰值
3. **Vref 软启动**：让环路追一个缓慢上升的基准，别让它一上来就要求满增益

启动时最容易把环路逼进容性区的，是**输出电容太大、充电电流太大**——Q 一高，峰值增益掉下来，环路一路往下压，压过 `fpeak` 就进去了。该防的是"电流太大"，不是"电压太低"。

## 第 6 章 1% 占空比能不能发出来

### 6.1 三个时间尺度

窄脉冲能不能成立，取决于它和这三个量谁大：

| 量 | 典型值 | 说明 |
|---|---|---|
| 死区 `t_dead` | 150 ~ 300 ns | 防止直通，必须留 |
| 驱动传输延迟差 | 50 ~ 150 ns | 光耦/隔离驱动的上升沿延迟 |
| MOS 完全开通时间 | 100 ~ 300 ns | 含密勒平台 |

### 6.2 算一遍

以 200 kHz、`d = 1%` 为例：

```
T   = 1 / 200k = 5 μs
脉宽 = 5 μs × 1% = 50 ns
```

**50 ns 比死区还短。** 这个脉冲物理上发不出来——它会被死区逻辑吃掉，或者被驱动器的最小脉宽限制截断，或者 MOS 根本来不及进入低阻区。

再看企业工程：`SHRTIMER_MIN_DUTY = 0.05`，250 kHz 下 5% = **200 ns**，而 `LLC_DEADTIME = 120` 计数 @ 680 MHz = **176 ns**。

**他们选的起点正好卡在"脉宽 ≈ 死区"这条线上，一步都不往下走。** 这不是保守，这是物理下限。

### 6.3 窄脉冲的真实代价

即使脉冲勉强发出来了，还有两个问题：

**（1）你想避免的不对称，反而被窄脉冲制造出来。** 两个脉冲的宽度理论上相等，但一个可能被最小脉宽截断，一个可能被体二极管续流补掉，实际伏秒就不等了。这才是真正的偏磁来源。

**（2）丢 ZVS。** 空档期两个管子都关断，谐振电流走体二极管续流，中点被钳位。下一个脉冲到来时，管子面对的是满电荷的结电容，硬开通。

硬开关损耗可以算：

```
P_hard = 2 × ½ · Coss · Vin² · fs
```

以 `Coss = 0.5 nF`、`Vin = 400 V`、`fs = 200 kHz` 计：

```
P_hard = 0.5e-9 × 1.6e5 × 2e5 = 16 W
```

但注意：**如果这段只持续 10 ms，总能量只有 0.16 J，热上完全不是问题。** 真正的代价是 `dv/dt`——400 V / 20 ns 的边沿，几十 pF 的耦合电容就能在采样线上注入几百 mA 尖峰，表现为**过流误保护**和**ADC 采样错位**，而不是管子发烫。

企业代码里那个"输出过压用电压抬升速率检测"（带载时记录 `vtemp`，`Vout` 比之前高 3 V 直接关机），就是被这个逼出来的。

### 6.4 结论

- 占空比下限不低于 **10%**，并用电流探头确认实际栅极波形
- 如果必须更窄，说明你的 `Mmin` 设计有问题，应该改谐振腔参数，而不是硬压脉宽

## 第 7 章 拆解一份企业级工程

### 7.1 规格

| 项 | 值 | 出处 |
|---|---|---|
| 输出功率 | 1650 W | `OUTPUT_POW_MAX` |
| 输出电流 | 30 A | `OUTPUT_CUR_MAX` |
| 待机保持电压 | 30 V | `CON_VOLT_OUT` |
| 最高电池电压 | 58 V | `MAX_BAT_VOLT` |
| 过压保护 | 65 V | `HW_VOLT_OVP` |
| 最高频率 | 250 kHz | `POW_MAX_PLV` |
| 最低频率 | 60 kHz | `POW_MIN_PLV` |
| 死区 | 120 计数 ≈ 176 ns | `LLC_DEADTIME` |
| 定时器时钟 | 680 MHz | `SHRTIMER_PLV` |
| 快环频率 | 40 kHz | `POW_INT_PLV` |

注意输出范围是 **0 ~ 58 V**，而 LLC 的 PFM 只能覆盖其中一段。这个"范围不匹配"就是整个设计的出发点。

### 7.2 四段式状态机

```
SoftStar → BmsStar → SoftCurSt → ConVolt → ConCurPWM → Transition → OvLoadPFM
                                                        ↑
                                              真正的"软启动"在这里
```

| 模式 | 发波 | 覆盖区间 | 任务 |
|---|---|---|---|
| `ConVolt` | 120 kHz 定频，`d = 1% ~ 15%` | 30 V 待机 | 把 LLC 当 buck 用，硬顶 |
| `Transition` | 250 kHz 钉死，`d = 0.05 → 0.449`，10 ms | 0 → `Mmin` | **补量程，不是软启动** |
| `OvLoadPFM` | `d = 0.5`，`f = 250k → 60k` | `Mmin` → 58 V | 正常工作 |

**这张表是全篇的钥匙。** 它说明：`Transition` 那一段的存在理由，不是"要慢慢启动"，而是"输出电压有一段在 `Mmin` 以下，频率够不着"。

### 7.3 发波实现

见 3.4 的代码。核心是 `pre = 680MHz / f`，然后按模式分两套 CMP。

### 7.4 交接逻辑

```c
case Transition:
    DriverPwm.Plv  = POW_MAX_PLV;              /* 250 kHz，钉在最高频 */
    DriverPwm.Duty = time * 0.001f + 0.05f;    /* 0.05 → 0.45 */
    if (time >= 400) {                          /* 40 kHz × 400 = 10 ms */
        piStructInter.integral = POW_MAX_PLV * 0.00002f;
        Ctrl_interFace.CtrMode = OvLoadPFM;
    }
    break;

case OvLoadPFM:
    flvOut = PI输出 * 50000.0f;
    if (flvOut > POW_MAX_PLV) { flvOut = 250000; integral = 250000 * Ki; }
    if (flvOut < POW_MIN_PLV) { flvOut =  60000; integral =  60000 * Ki; }
    DriverPwm.Duty = 0.5f;
    break;
```

**这就是完整的两段式：** A 段 `f` 钉在 `fmax`、`d` 从 5% 爬到 45%（10 ms）；交接点 `(0.45, 250 kHz)`；B 段 `d = 0.5`、`f` 从 250 kHz 往下扫。

### 7.5 三个值得抄的细节

**（1）积分器抗饱和的写法**

钳位时直接把 `integral` 置成 `clamp值 × Ki`，让 PI 输出正好等于钳位值。这样退出钳位时不会有积分回绕，比只写 `if (out > max) out = max` 干净得多。而且上下两个方向都钳了——60 kHz 就是防容性区的最后一道闸。

**（2）输出过压用"电压抬升速率"检测**

带载时记下 `vtemp`，如果 `Vout` 突然比之前高 3 V，直接判过压关机。这比固定 OVP 阈值快得多，专门抓"环路失控、输出飞掉"这种工况——正好对应容性区失控。

**（3）同步整流的开关都带电流门限和延时**

`iOut > 4 A` 连续 1000 拍才开 SR，`iOut < 2 A` 立刻关。软启动和轻载阶段不开 SR，避免 SR 误导通。

### 7.6 四处不能照抄

| 位置 | 它的做法 | 为什么你不能抄 |
|---|---|---|
| `Transition` 入口 | 从 80 k / d≈0.3 硬跳到 250 k / d=0.05 | 这是充电机，**电池把输出钳住了**，`Vout` 掉不下去。电压源带容性负载这么跳会明显跌落 |
| `ConVolt` | 120 kHz 定频 + 占空比调压保持 30 V | 本质是把 LLC 当 buck 用，效率低。只适合短时待机，不适合长时间 |
| PFM 段 SR | `DriverPwm.SynDrv = 0`，SR 代码全注释 | 这一版**放弃了同步整流**，别以为那是标配 |
| `d` 起点 | 5% | 因为它 250 kHz 下 5% 正好等于死区。你的频率不同，这个数要重算 |

## 第 8 章 两种软启动策略的完整对比

### 8.1 定义

**方案一：PWM + PFM 混合软启动**

固定频率（取 `fmax`），占空比从下限爬到 0.45（对称发波，上下管导通时间同步增加，中间留空档），然后占空比固定 0.5，开始调频。

**方案二：纯 PFM 扫频软启动**

从远高于 `fmax` 的初始频率起扫，全程 50/50 互补（扣除固定死区），在几十毫秒内平滑降到目标频率。

### 8.2 对比矩阵

| 维度 | 方案一（混合） | 方案二（纯扫频） | 说明 |
|---|---|---|---|
| 稳态直流偏磁 | **无** | **无** | Cr 隔直，两者都自动平衡 |
| 瞬态伏秒不平衡 | 有（`d` 爬坡时 Cr 充电） | 有（起扫瞬间 Cr 从 0 建立） | 两者都有，量级都不大 |
| 磁通摆幅 | **更小**（∝ d） | 最大（满伏秒） | 反直觉，但这是事实 |
| ZVS | **丢**（空档期硬开通） | **保** | 方案一的主要代价 |
| 硬开关损耗 | 16 W 量级（10 ms → 0.16 J） | ≈ 0 | 热上不致命，EMI 上致命 |
| 电流应力对称性 | 差（两管不均） | 好 | 影响温升分布 |
| 冲击电流抑制 | 好（脉宽限能量） | 极好（高频高阻抗） | 两者都够用 |
| 副边电压应力 | 较高（硬开关尖峰耦合） | 低 | — |
| 控制复杂度 | 高（两套发波 + 交接） | 低（只改周期寄存器） | — |
| 适用输出范围 | **宽**（可低于 `Mmin`） | 窄（必须高于 `Mmin`） | **这才是选型的决定因素** |

### 8.3 四条需要修正的说法

**（1）"小占空比必然直流偏磁、导致饱和"——错**

Cr 是隔直电容，稳态伏秒自动平衡。磁通摆幅 ∝ d，小占空比离饱和更远。真正的风险是"脉宽 < 死区/驱动延迟"导致两个半周实际导通时间不等。

**（2）"硬开关损耗巨大"——对，但量级要算清**

`2 × ½·Coss·Vin²·fs`，0.5 nF / 400 V / 200 kHz 下约 16 W。持续 10 ms 只有 0.16 J，热上无感。**真正的伤害是 `dv/dt` 引起的采样干扰和误保护。**

**（3）"高频起扫 ZVS 极易实现"——方向反了**

励磁电流峰值 `Im = Vin/(4·Lm·fs)`，**与频率成反比**。ZVS 判据：

```
½·Lm·Im² ≥ Coss·Vin²
```

代入得最高可 ZVS 频率：

```
fs_ZVS_max = 1 / sqrt(32·Lm·Coss)
```

以 `Lm = 200 μH`、`Coss = 0.5 nF` 计，`fs_ZVS_max ≈ 559 kHz`；若 `Coss = 1.5 nF`，只有 **323 kHz**。

**所以"抬 fmax 来扩增益范围"这条路，是用起扫段的 ZVS 余量换的。** `fmax` 翻倍，可用能量掉到 1/4。这是纯扫频方案自己的边界。

**（4）"工业界无一例外用扫频"——不成立**

L6599、UCC25600、C2000 参考设计确实都是扫频，那是因为它们的输出范围窄。宽范围产品用混合的一大把——本文分析的那台 1600 W 充电机就是。

### 8.4 结论

**如果 `Vout_min > Mmin·Vin/n`，方案二全面胜出，不要碰占空比。**

**如果 `Vout_min < Mmin·Vin/n`，方案二物理上做不到**，必须混合。但混合的 A 段终点必须是 **0.45**，且 A 段结束时 `Vout` 落在 `Mmin` 附近，不要用它去够目标电压。

## 第 9 章 为什么工程要用混合：Mmin 才是答案

### 9.1 三段代码对应三个电压区间

```
0 V ─────────── 30 V ─────────── 40 V ─────────── 58 V
   ConVolt        │   Transition  │    OvLoadPFM
   (PWM 硬顶)     │  (d 爬坡)     │   (PFM 扫频)
                  │               │
              低于 Mmin        Mmin 以上
```

- **0 ~ 30 V**：`ConVolt`，120 kHz 定频 + 1%~15% 占空比
- **30 ~ 40 V**：`Transition`，250 kHz 钉死 + `d` 从 5% 爬到 45%
- **40 ~ 58 V**：`OvLoadPFM`，`d = 0.5` + 频率下扫

所以你的判断——"因为 30~40 V 是非工作区间"——**方向是对的**。但准确说法不是"非工作区间"，而是"**PFM 不可调区**"。它照样能工作，只是必须换一个旋钮。

### 9.2 硬开关是代价，不是目的

"这个区间需要硬开关驱动"这句话要改。你需要的是**第二个调节自由度**，占空比只是最便宜的那个，它碰巧丢 ZVS。

### 9.3 四条替代路径

| 方案 | 保 ZVS | 代价 | 适用 |
|---|---|---|---|
| burst（间歇） | 基本保 | 输出纹波、音频噪声、轻载效率 | 待机保持，不适合带载爬升 |
| 降低 `Mmin`（加大 `Ln` / 改匝比） | 保 | 牺牲峰值增益和效率 | 输出范围窄时 |
| 前级预稳压 / 线性预充 | 保 | 成本、体积、效率 | 小功率 |
| 占空比 PWM | 丢 | 硬开关、EMI、电流不对称 | **宽范围 + 短时 + 负载钳位** |

### 9.4 它能用 PWM 的三个前提

企业工程敢用最后一条，是因为三个条件同时成立：

1. **时间短**：10 ms，0.16 J，热容扛得住
2. **负载钳位**：后面是电池/大电容，`Vout` 顶不飞，所以不怕 PWM 段的增益台阶
3. **该段功率低**：30 V / 16 A 也就 480 W，硬开关损耗占比可接受

**如果你是电压源带容性负载，第 2 条不成立。** 这就是为什么这份代码敢从 80 k / d≈0.3 硬跳到 250 k / d=0.05——电池把输出钉住了。你照抄会看到明显跌落。

## 第 10 章 设计规则与验证

### 10.1 决策树

```
开始
 │
 ├─ Vout_min > Mmin·Vin/n ？
 │    ├─ 是 → 纯 PFM 扫频
 │    │        fstart = 1.2~1.5 × fmax
 │    │        50/50 互补，d 全程不变
 │    │        fmin 硬钳位在 fpeak 之上 10%
 │    │
 │    └─ 否 → 必须混合
 │              A 段：f = fmax，d: 0 → 0.45
 │              A 段结束时 Vout 落在 Mmin 附近
 │              B 段：d = 0.5，f: fmax → f_op
 │
 └─ 只需要一个低压待机点？
      └─ 单独做 ConVolt 或 burst，不要混进软启动路径
```

### 10.2 四个关键公式

**（1）增益与占空比**

```
M(d) / M(0.5) = sin²(π·d)
```

用途：估算交接台阶。`d = 0.45` 时只有 2.5%，`d = 0.3` 时是 53%。

**（2）Cr 的直流工作点**

```
Vcr = d · Vin
```

用途：核算电容电压应力；判断 `d` 跳变时的充电电流。

**（3）磁通摆幅**

```
ΔB = (Vin/2) · d · T / (N · Ae)
```

用途：确认小占空比下磁通更安全，而不是更危险。

**（4）ZVS 频率上限**

```
fs_ZVS_max = 1 / sqrt(32 · Lm · Coss)
```

用途：判断 `fmax` 能不能再往上抬。

### 10.3 验证清单

| 项 | 怎么测 | 合格判据 |
|---|---|---|
| 频率指令 | 抓 DAC 或调试变量 | 全程不低于 `fpeak` 钳位 |
| 原边电流对称性 | 带复位的电流互感器或罗氏线圈 | 正负对称，基线不漂 |
| Cr 电压 | 高压差分探头 | 稳态在 `d·Vin` 中心 |
| ZVS | 看 `Vds` 关断波形 | 无密勒平台后的振荡，无硬开关尖峰 |
| 两管温升 | 分别测壳温 | 差值 < 5 ℃ |
| 交接点 | 同时抓 `Vout` 与频率 | 过冲 < 5%，频率不触顶 |
| 三种工况 | 空载 / 满载 / 输出短接 | 都能正常爬升 |

### 10.4 五个常见错误

1. **把对称发波和互补发波当成两种模式去"切换"** —— 它们是同一个旋钮的两端
2. **用占空比去够目标电压** —— 交接时频率无路可走，必然振荡
3. **认为低压侧是容性区** —— 容性区在低频侧，低压侧反而最安全
4. **认为小占空比会导致磁饱和** —— Cr 隔直，小占空比磁通摆幅更小
5. **把 `fmax` 当无限可调** —— ZVS 余量按 `1/f²` 衰减，抬高一倍掉到四分之一

## 结语

回到最初那个问题："我要对称发波，是因为不对称发波会导致磁不平衡、发烫，我讲得对不对？"

**直觉对了一半，但对的那一半不在你以为的地方。**

半桥 LLC 里不存在"稳态直流偏磁"这个问题——Cr 就是为此存在的。真正存在的是三个东西：**窄脉冲导致的实际伏秒不等**、**空档期丢失的 ZVS**、**占空比带来的增益粗调台阶**。

而"30% 跳 50% 会振荡"的根本原因，也不是切换动作本身，是**频率已经顶到上限、没有余量**。台阶只是把这个矛盾暴露出来的触发器。

所以正确的动作不是"想办法平滑地切换"，而是**别让它需要切换**：把占空比老老实实爬到 0.45，让 `Mmin` 对应的电压自己出现在交接点上，然后只调频率。
