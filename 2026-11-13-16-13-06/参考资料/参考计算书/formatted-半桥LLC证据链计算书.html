第 0 章　证据链的元规则

一份计算书最容易骗人的地方，不是公式写错，而是没说清每个数字凭什么可信。本章先把"可信"这件事拆成可判定的四件事：模型等级、数据来路、证据编号、禁止事项。后面 12 章全部按这四件事登记。

0.1　三类失败与各自的检出手段

类别典型形态为什么危险检出手段
A 类：算错系数用错（半桥用成全桥）、单位错、括号错数值明显偏离，容易被发现回代校核、两种写法互验（见推导册 6.3）
B 类：模型不适用FHA 用在深断续区；用 FHA 声称 ZVS 精细余量数值"看起来对"，但物理不成立；最危险有效性闸门（第 4 章）+ 模型适用域声明（第 2 章）
C 类：没算却当算过Qrr 填 0、Eoss 忽略、Qoss 用 Coss*V 不标注不报错，不偏大，只是悄悄少了十几瓦ModelGrade + DataConfidence（0.3、0.4）+ 损耗台账（第 8 章）

本册的主要篇幅用在 B 类和 C 类。A 类靠推导册的校核表解决，不在这里重复。

0.2　五级保真度阶梯

同一个问题，不同模型能给出的答案精度差好几个数量级。把模型按保真度排成阶梯，任何结论都要标注"我用的是第几级"。

级别方法能回答不能回答本设计是否使用
L0FHA 相量法（基波近似）增益、工作频率、基波电流、谐振腔阻抗谐波、振铃、精确 ZVS 余量、开关损耗是（主设计工具）
L1非线性多谐波平衡波形畸变、增益修正、谐波电流占比瞬态、寄生振荡否（仅作偏差评估）
L2内部开关时域（分段线性）真实峰值电流、ZVS 波形、死区过程器件非线性、寄生参数否（无此工具）
L3共享 ngspice 时域寄生振荡、SR 反向恢复、母线交互器件热行为、磁芯损耗否
L4器件级 SPICE（厂商模型）开关损耗、EMI 源、栅极振铃仍需热模型与磁模型配合否
L5硬件实测一切，但代价最高—否（打样前）

规则：结论的可信等级不得超过其所用模型的级别。L0 得出的"ZVS 余量 10 倍"只能是 PARTIAL，不能是 ALIVE——因为 FHA 看不见死区里的真实波形。这条规则是整册的地基，违反它的结论一律作废。

0.3　ModelGrade：结论的可信等级

等级含义可否写进交付结论典型场景
ALIVE模型在该工作点已通过有效性闸门，且数据来自手册或实测可以，可直接作为设计依据L0 在谐振点附近的增益
PARTIAL模型只覆盖了部分物理，或数据有一项是假定可以，但必须带限定语FHA 给的 ZVS 电荷余量
APPROXIMATION用了明确的近似公式，误差方向已知可以，但必须标误差方向Qoss ≈ Coss*V、三角波等效纹波
ESTIMATED数量级可信，绝对值不可信只能用于相对比较磁芯损耗、绕组交流电阻
UNKNOWN没有数据，或模型不覆盖不可以，必须进未决项SR 结温、母线纹波实测值

关键点：UNKNOWN 不等于 0，也不等于没问题。它只表示"这一项没有证据"，而一项没有证据的约束，在交付判定里按最坏处理。

0.4　DataConfidence：数据的来路

置信度来源示例
DATASHEET器件手册的图表或表格，按实际工作点读取Qoss(Vds=400V)、Rds(on)@Tj=100°C
MEASURED本机实测（含打样后的复测）变压器漏感、绕组直流电阻
DERIVED由其他证据推导，链条可追Rac 由 Vo/Po/Vf 推出
ASSUMED工程假定，无来源Rdson = 30 mΩ、Pcore = 8 W
MISSING应当有但没有磁芯手册缺 k_st/alpha/beta

组合规则：ModelGrade 取"模型等级"与"数据置信度"中较低的一个。例如 FHA（PARTIAL）× Qoss 用近似（APPROXIMATION）→ 该 ZVS 结论的最高等级是 APPROXIMATION。

0.5　证据编号规则

EV-<域>-<两位序号>

域代码：
  SPEC  规格与需求        MOD   模型适用域
  CAL   口径定义          CALC  计算中间量
  GATE  闸门判定          SIM   仿真或高保真复核

每个进入结论的数字，背后必须有一个 EV 号；每个 EV 号必须能追到"哪一级模型 + 什么数据来源 + 谁判定的"。第 12 章的台账就是全部 EV 的汇总。

0.6　三条禁令

  1. 禁止把 FAIL 改名成 PASS。判据不通过就是不通过，只能改设计、改判据并留痕，不能改结论文字。历史上最常见的做法是把"未通过"写成"满足要求（有裕量）"，这属于造假。
  2. 禁止把 UNKNOWN 当成 0 或当成"没问题"。没有证据的项，在交付判定里按最坏处理；要么补证据，要么显式接受风险并签字。
  3. 禁止用近似值冒充手册值。凡是用 Coss*V 代替 Qoss(V)、用直流电阻代替交流电阻的，必须在同一行标 ModelSource；不标即视为造假。

为什么单独立一章讲"管理"：工程上真正翻车的项目，多数不是算不出来，而是算出来的东西被当成了另一回事——FHA 的余量被当成实测余量，假定的损耗被当成实测效率，未做的校核被当成已做。证据链的作用就是让这种"偷换"无处藏身。

第 2 章　模型适用域声明

2.1　FHA 的四条前提

FHA 不是"近似一下"，它建立在四条明确假设上。任何一条被破坏，结论就要降级。

#前提本设计是否满足破坏后的表现
P1谐振腔电流接近正弦（工作点靠近 fr）满足（fs/fr = 1.11）峰值电流低估、增益偏差 > 10%
P2整流网络可等效为纯电阻 Rac = 8n²Ro/π²满足（全波整流、电流连续）轻载断续时 Rac 失真
P3开关网络只输出基波满足（占空比 50% 对称）占空比不对称时出现偶次谐波
P4死区足够短，换流过程不影响主波形部分满足（t_dead/Ts = 2.7%）ZVS 过程被 FHA 完全忽略

P4 是"部分满足"，这一条直接决定了：凡涉及死区、ZVS、开关损耗的结论，最高等级只能是 PARTIAL。这不是保守，而是模型边界。

2.2　FHA 明确不能声称的六件事

  1. 不能声称 ZVS 有精确余量。FHA 给的 Im 是基波幅值，真实换流电流是三角波加无功分量，两者差 20% 以上。只能声称"按电荷判据估算，余量充足/不足"。
  2. 不能声称无振铃、无过冲。振铃来自寄生电感与 Coss，FHA 里根本没有这些元件。
  3. 不能声称开关损耗。ZVS 开通损耗近似为零是假设，不是结论；关断损耗需要电流波形与 Coss 非线性，FHA 给不了。
  4. 不能声称 SR 应力。副边电流的换向尖峰、反向恢复都在 FHA 之外。
  5. 不能声称轻载/空载行为。Rac → ∞ 时 FHA 退化为空载增益曲线，与实际跳频、burst 模式无关。
  6. 不能声称瞬态与保护。启动冲击、短路、母线跌落过程全部在 FHA 之外。

这条清单的用法：写报告时如果出现"ZVS 可靠实现"、"损耗低"、"无振荡"这类判断，回头查它落在哪一条里。落在 1～6 里的，必须补一句"以上为 FHA 估算，未经时域验证"。

第 3 章　计算内核与口径台账

3.1　内核公式（引用，不推导）

以下公式的推导过程见《半桥 LLC 谐振变换器计算书 V1.1》第 3、5、6 章，本册只登记其身份与口径。

Rac   := (8/pi^2) * n^2 * Vt^2 / Pt        // Vt = Vo+Vf, Pt = Po*Vt/Vo
Z0    := Qmax * Rac
Lr    := Z0 / (2*pi*fr)
Cr    := 1 / (2*pi*fr*Z0)
Lm    := Kratio * Lr
Zr(f) := 1i*(2*pi*f*Lr - 1/(2*pi*f*Cr))
Zp(f) := 1i*2*pi*f*Lm*Rac / (1i*2*pi*f*Lm + Rac)
Zin(f):= Zr(f) + Zp(f)
H(f)  := Zp(f) / Zin(f)
M(f)  := |H(f)|
phi(f):= arg(Zin(f))                        // 注意：不是 arg(H)

phi 的定义是口径问题，不是笔误问题。取 arg(Zin) 得 +20.35°（感性），取 arg(H) 得 −5.95°（数值上像容性）。若用后者，第 6 章的 C-04/C-05 会被判成"工作在容性区"，整台机器被误判为不可用。这就是 0.5 节要求给每个量编 CAL 号的原因。

3.2　工作点求解策略

增益曲线非单调，单区间求根会漏解。本设计与工具的求解策略对照：

环节工具的做法本册的做法差异后果
找根geomspace 1600 点扫描 + 逐区间 brentq，取全部根按 M_req 与 1 的大小分两支二分工具更稳（不漏解），本册更快（适合手算/录入）
过滤保留 input_phase_deg >= 3.0°保留 phi > 0工具的 3° 死区更保守，能挡住"刚好在容性边界"的解

证据判定：两种策略在 400 V / 380 V / 420 V 三点给出完全一致的频率（133.54 / 112.05 / 153.60 kHz），互验通过，登记为 EV-CALC-01，等级 ALIVE。

常见错法：写成 √2*|Zp|/(2π*fs*Lm)，漏了 I1_peak。量纲上像"电压除以阻抗"，实际等于假设输入电流为 1 A，结果只有 0.35 A，比值变成 22 倍。校验办法：算完就除一下，比值应当≈1.234；不是就说明公式漏项。

第 4 章　FHA 与 TD 的有效性闸门

FHA 是近似，问题是什么时候这个近似失效。靠"经验感觉"判断不行，必须给出可执行的阈值。本章采用与工具一致的三指标、双阈值（警告 / 失败）体系。

4.1　阈值表

4.2　判定逻辑

status(dev, warn, fail) :=
  if  |dev| >= fail  -> "FAIL"
  else if |dev| >= warn -> "WARN"
  else -> "PASS"

gate := worst( status_gain, status_freq, status_phase )
  // worst: FAIL > WARN > PASS，任一 FAIL 即整闸 FAIL

三指标取最差，不做加权。理由：三个指标测的是同一件事（FHA 是否还成立）的不同侧面，任何一个崩了都说明模型不能用，加权平均会把崩塌平均掉。

4.3　关键案例：闸门正确、口径错误

这是本册最重要的一节，值得完整复盘。

背景：用工具跑一台 400 V → 53 V / 3 kW 的全桥 LLC，优化器给出 4 个候选，参数看着都合理（Lr = 23.78 µH、Cr = 106.51 nF、Lm = 118.91 µH、fs = 99.69 kHz），但4 个全部被闸门拒绝，失败项都是同一条：

magnetizing_current_peak_a : FAIL
偏差范围 20.3% ～ 27%

直觉判断：20%～27% 的偏差，超过 20% 的失败阈值，看起来是"FHA 在这个工作点不成立"，于是结论会是"这个设计点太靠近容性区，要改 K"。

真实原因：闸门比较的是两个不同口径的励磁电流——FHA 侧给的是基波幅值，时域侧给的是三角波峰值。两者的理论比值是：

Im_tri / Im_fha = pi^2 / 8 = 1.2337   ->   偏差 23.4%

23.4% 正好落在观测到的 20.3%～27% 区间中央。这不是模型失效，是口径不一致。

判读闸门输出实际含义正确处置
表面FAIL（偏差 > 20%）"FHA 不成立"改 K、改 Qmax、放弃该点
实际FAIL（偏差 > 20%）"两个数不是同一个东西"统一口径后重跑，不要改设计

证据链教训：闸门只能报告"两边不一致"，无法区分"模型失效"和"口径不同"。所以闸门旁边必须挂着口径台账（3.3 节）。没有台账的闸门，会把好设计误杀，而且误杀的理由看起来很专业——这比漏判更危险。

反推：如果 4 个候选的偏差都在 23% 附近且高度一致，基本可以断定是口径问题；如果偏差散布在 5%～40% 之间，才是真的模型失效。

本设计的处置：登记 EV-GATE-01，把换算系数 1.234 写进 EV-CAL-01，闸门两侧都换算到三角峰值口径后再比较。换算后本设计在 400 V 满载点的励磁电流偏差为 0%（同口径同公式），闸门自然通过。

4.4　闸门 FAIL 的三条处置

  1. 先查口径，再查模型。按 3.3 节逐条比对：励磁电流（π²/8）、Rac（含不含 Vf）、相角（Zin 还是 H）、桥臂因子（0.5 还是 1）。这四项能解释 90% 的"莫名偏差"。
  2. 口径一致后仍 FAIL，才动设计。此时按 2.2 节的清单确认是哪条前提被破坏，通常是 P1（离 fr 太远）或 P2（轻载断续）。
  3. 不许"调参救活"。见 10.3：不允许为了让闸门通过而微调 Rac、fs 或 Im 的取值。允许的只有"统一口径后重跑"并登记。

第 5 章　稳态闸门

5.1　收敛判据

时域模型给出的"稳态值"只有在确实进入稳态后才有意义。判据：相邻两个开关周期的状态量残差小于阈值。

converged := max| x[n+1] - x[n] | < tol
  其中 x = [i_Lr, v_Cr, i_Lm, v_Co]
  tol 取 1e-3（相对量）
状态含义对结论的影响
converged = true已进入周期稳态可用该结果做闸门比较
converged = false仍在暂态，或存在次谐波振荡所有基于该结果的结论最高 UNKNOWN

5.2　未收敛时的结论上限

未收敛的三种原因与处置：

原因特征处置
仿真时长不够残差单调下降但未达标延长仿真周期数（通常 200 周期够）
存在次谐波/分岔残差在两个值之间跳这是真实物理，不是数值问题；该工作点不可用，进 FAIL

6.3　"不可达"算 FAIL 还是 UNKNOWN

本设计的 C-02（330 V 保持时间）返回 NaN。这属于哪一态？

判读是否成立理由
UNKNOWN（"算不出来，可能是求解器问题"）不成立已独立验证：全频段峰值 1.0905，需求 1.1733，数学上确定不存在解。不是求解器无能。
FAIL（"该工况确实做不到"）成立增益上限由 K 与 Qmax 唯一决定，与算法无关。

区分方法：把"不可达"拆成两步验证——① 扫全频段确认峰值确实小于需求（这一步排除求解器漏解）；② 检查峰值是否被 Qmax 的取值决定（这一步确认是设计问题不是数值问题）。两步都过了，就是 FAIL，不许挂 UNKNOWN 拖着。

反过来，如果只跑了一次求解器就报 NaN，那确实是 UNKNOWN——因为 7.1 节说过，单区间求根会漏解，NaN 可能只是"没搜到"。

这是单目标优化器最容易漏掉的一点："最恶劣"不是一个点，是三个点，而且它们互相冲突。

第 8 章　损耗的证据分级

8.1　LossTerm 结构

每个损耗项不是一个数字，是一个四元组。少了后三项，这个数字就不能进结论。

LossTerm := {
  P_w          : 数值
  grade        : ALIVE | PARTIAL | APPROXIMATION | ESTIMATED | UNKNOWN
  confidence   : DATASHEET | MEASURED | DERIVED | ASSUMED | MISSING
  source       : 公式编号 或 数据出处
}

8.2　三项不许填零

项常见"填零"做法实际量级后果
Rds(on)@Tj用 25°C 值，或直接填 0100°C 时比 25°C 高 40～60%导通损耗低估 40%，结温估算偏低，热设计失效
EossZVS 就认为开通损耗为 0仍有 Coss 储能回灌损耗本例 P_off = 4.27 W，占总额 10%
Qrr（SR 体二极管）同步整流就认为无反向恢复死区期间体二极管导通，有 Qrr尖峰电压、额外损耗、EMI

为什么这三项总被填零：因为它们"看不见"——ZVS 听起来就没有开通损耗，同步整流听起来就没有二极管损耗，25°C 的 Rds(on) 就在手册第一页。填零不需要查任何资料，而查资料要花时间。证据链的作用就是让"省事"这件事留下痕迹：填零必须写成 ASSUMED，交付时会被点名。

8.3　电热迭代

损耗依赖结温，结温依赖损耗，必须迭代到不动点：

Tj[0] := 25 C
repeat:
   P[k]  := sum( LossTerm(Tj[k]) )
   Tj[k+1] := Tamb + P[k] * Rth_total
until |Tj[k+1] - Tj[k]| < 1 C
收敛后：所有 LossTerm 的 grade 升一级（因为用了自洽的 Tj）

不迭代的后果：用 25°C 的 Rds(on) 算出的损耗偏低，算出的 Tj 偏低，于是"验证"了 25°C 的假设——这是一个自我印证的循环，永远收敛不到真实值。典型的偏差是结温低估 20～30°C。

第 9 章　ZVS 的电荷证据

9.1　换流电流的三种口径

同一个"换流电流"，三种算法差 40% 以上。必须登记用哪一种。

口径公式本设计数值适用偏差
只用励磁电流（三角峰值）Im = n*Vt/(4*Lm*fs)7.77 A仅当 phi ≈ 0（恰在谐振点）低估 34%
只用谐振电流无功分量|I1_peak*sin(phi)|8.81 A远离谐振点、重载轻载时低估（Im 占比上升）

0.75 这个系数的含义：励磁电流在死区开始时并不在峰值（三角波在峰值附近停留很短），取 0.75 作为保守估计。它不是物理常数，是工程折中，必须标注为 APPROXIMATION。

为什么不直接用"两者相加"：Im 与 I1_peak*sin(phi) 在换流时刻方向相反——励磁电流此时正把中点往一个方向推，谐振电流的无功分量往另一个方向推，真实换流电流是两者之差。取 max 是"宁可高估"的保守做法；取和会高估得更多，取差会在某些角点变成负值（物理上意味着 ZVS 已经丢了）。

结论的正确写法：

按电荷判据估算，ZVS 余量充足（额定 10.0 倍，最差角 4.4 倍）。Qoss 用线性近似，真实需求电荷更大，故实际余量略低于上述值。该结论未经时域验证，不构成"ZVS 可靠实现"的证明。

错误的写法（常见）："ZVS 余量 10 倍，可靠实现。" —— 省略了近似来源与模型边界，把一个 APPROXIMATION 级的结论说成了 ALIVE 级。

10.3　拒绝规则

这是证据链最容易被破坏的环节。规则：

  1. FAIL 候选不得通过"微调参数"救活。允许的只有两种：① 发现口径错误，统一后重跑（须登记，见 4.3）；② 换设计点重新进入 Stage A。
  2. 不得对判据做"合理性调整"。例如把 kIm 上限从 0.45 放宽到 0.55 以接受 K = 4——如果要放宽，必须作为独立决策记录，说明理由与代价，不能在优化器里悄悄改。
  3. 不得用加权分数掩盖单项 FAIL。综合分高的候选如果某一项 FAIL，仍然出局。加权只能用于排序 PASS 候选，不能用于"平均掉"失败项。

工具的实践：工具的两阶段优化器在 Stage B 里对 FAIL 候选直接拒绝，不做加权补偿。这个设计是对的，也是它最值得借鉴的地方之一。代价是会出现"4 个候选全被拒"的情况（4.3 节的案例）——但那是口径问题，不是拒绝规则的问题。

关于 EV-GAP-01 的具体纠正：工具（以及很多计算书）用的 C_div >= Po*T_line/(2*Eta*Vbus*DeltaV) 来自半桥正激——那里分压电容确实要给负载供能。LLC 不是：Cr 已在谐振腔里隔直（VCr_dc = Vbus/2），负载电流走"母线 → 上管 → 谐振腔 → 下管 → 地"，不经过分压电容，i_r 无直流分量，分压电容净平均电流为零。按正激公式算得 4.9 mF，按职责算得 3.78 µF，差 2500 倍。

同样，纹波电流不是 Iin/2 = 3.9 A @ 100 Hz，而是 I1_rms/2 = 8.96 A @ 133 kHz。频率错了 1300 倍，薄膜电容的允许纹波电流在这个频段完全不是手册首页那个数。

判定规则（按严格程度递增）：

CONDITIONAL PASS   : 无 FAIL，但有 WARN 或 UNKNOWN（须列清单 + 关闭计划）

交付结论：CONDITIONAL PASS（条件通过）——但附两个硬条件。

  1. 方案 A 不得用于有 330 V 保持时间要求的场合。若该要求存在，必须改用方案 D（Qmax = 0.35、K = 8，M_peak = 1.249，保持余量 6.4%），此时 C-02 转为 PASS、C-03 转为 PASS。
  2. C-11 必须关闭后才能出规格书。关闭方式：实测母线纹波 + 确认输出电容 ESR。

在两条硬条件满足前，本设计不具备打样条件。这不是保守，是 6.2 节的升级禁令：FAIL 不能降级为 WARN，UNKNOWN 不能当成"应该没问题"。
