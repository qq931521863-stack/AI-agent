## 追加（同日，v2 → v2.1）：上一版是错的，已实跑修好

**教训（写给以后的自己）**：`_validate.py` 结构校验全过，但 PLECS 里一跑就报
`Unconnected terminals overlapped by other elements`。**结构校验 ≠ 能仿真**，必须真跑。

**两个真原因**
1. 克隆的 Scope 块 `Axes="2"` 只有 2 个输入端子，上一版接了 1~4 / 1~6，3 号以后不存在 → 线悬空横穿元件。
2. 分叉线（`Branch`）没写 `Points`，PLECS 按直线画过去，压在别的元件端子上。

**v2.1 做法**
- 删 `LEAD7`/`Constant2`/`RE1`（旧三角波调制器）及 3 条线。
- **一条 Branch 都不用**：全部一源一目标；要分叉的地方用 `Goto`/`From`（tag `PWM`）代替。
- 每个 Scope 只用 2 个输入；`Scope_TB` = TBCTR 状态口 + PWM，`Scope_SH` = Vo 采样 + Ipri 采样。
- 复位改成真通路：`From(DsCur)` → `RE_PKHIT(> I_PK)` → `TBCTR(3)`。`I_PK=1e9` 等于关掉峰值复位（定频 100kHz），
  改成实际值立刻变变频。这比之前的 `PulseGenerator` 自检脉冲实在。
- 用 `ConstantRelationalOperator`（单输入、阈值是参数）代替 `RE_CMPA`+`C_CMPA`，链变成纯水平直线。

**实跑验证（PLECS GUI 自动化，脚本 `_grab.py`）**
- 标题变 `..._v2 [running]`，无 Error / Diagnostics 弹窗。
- `Scope_TB`：TBCTR 0→1500 锯齿、10µs；PWM 从 750 起高，50%。
- `Scope_SH`：Vo 阶梯每级 20.2µs，0→106V→稳在 ~19V。
- `Scope11`：DRVH/DRVL 互补 50%，有死区，无重叠。

**发现但未修**
- 50kHz 采 HS 电流几乎全采到 0（采样点落在 LS 窗口）。TI 里峰值电流走 CMPSS 连续比较，不走 ADC。
  Step 4 要么连续比较（`RE_PKHIT` 方向已对），要么改 EPWM 触发 SOC。
- 启动第一个 HS 脉冲 `DsCur` 冲到 ~2e5 A，是原功率级行为（`RonPri=570e-12` 疑单位笔误），与 Step1/2 无关。

**PLECS GUI 自动化的关键约束**
- 工具调用一结束，子进程就被杀 → **启动/按键/截图必须写在同一个脚本、同一次调用里**。
- 主窗口标题会变成 `<model>/<active MDC child>`，按标题找窗口要按面积取最大，不能靠 `/` 过滤。
- 想让 Scope 自动弹出来，把 Scope 块的 `Open` 参数改成 `"1"`；Scope 输入端子数由 `Axes` 参数决定。
- `ImageGrab.grab(all_screens=True)` = 3840×1200（双屏）。
